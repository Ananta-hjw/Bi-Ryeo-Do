# 의뢰·무한비무대 난이도 기준

## 목표와 범위

메인 스테이지 상향 이후 선택 콘텐츠만 과거 수치를 사용하던 차이를 줄였다. 의뢰·탑의 개방 조건, 첫 클리어 판정, 경험치/은자/아이템/평판/인연 보상, 메인 전투 수치는 변경하지 않았다. 이미 획득한 보상을 다시 지급하거나 기록을 초기화하지 않는다. 전투 강도는 현재 플레이어에게 맞춰 자동 상승하지 않는다.

## 의뢰

3·4·6단계 의뢰의 기존 적 보정과 제한은 유지한다. 동료가 합류하기 전의 단독 전투와, 6단계 돌파 후 동료가 합류한 상황을 혼동하지 않는다.

15단계 이후 의뢰는 `StageStars.ScaleEnemy(raw, RefStage, 0)`로 얻은 **현재 일반 메인 적**에 의뢰 계수 1.10을 적용한다. 체력은 그 계수의 0.7제곱, 공격은 0.3제곱이며 방어·레벨은 메인과 같다. 독사굴은 생존 목표를 달성하기 전에 적이 전멸하던 문제를 줄이기 위해 체력을 추가로 1.25배 적용한다. 강한 파티가 먼저 전멸시키는 정상 승리 규칙은 유지한다.

| 의뢰 | 제한 아군 행동 수 |
|---|---:|
| 철각비마대 척후 격퇴 | 27 |
| 저잣거리 자객 소탕 | 37 |
| 혈마대 잔당 추격 | 68 |
| 살귀대 정찰조 제압 | 68 |
| 살룡대 잔당 추적 | 65 |
| 도전자 정리 / 중원표국 뒷골목 정리 | 76 |
| 십삼혈 잔당 수색 | 54 |

독사굴은 기존 적 18행동 생존 목표다. 안내문과 실제 제한을 함께 갱신했다. 출전 준비의 추천 종합 수치도 메인의 현재 준비 기준을 반영한다.

## 무한비무대

층별 적 곡선 레벨 `17 + 2 × 층`은 유지한다. 각 층은 그 곡선 레벨에 가장 가까운 메인 스테이지(8단계 이상)를 고정 기준으로 사용한다. 플레이어의 레벨/장비/현재 스토리가 적의 수치를 바꾸지 않는다.

- 기본 체력 배율은 일반 적 1.7, 보스 3.4다. 일반 적의 초기층 체력 보정은 1층1.25 → 13층1.0이다.
- 별도의 오래된 층별 공격 표를 제거했다. 기본 공격 배율은 일반 적3.3, 보스3.0이다.
- 정규화한 적에 기준 메인의 일반 체력·공격·방어 보정을 한 번만 적용한다. 높은 층의 체력이 기존 시험 전용 적 예외(`HpMul > 10`)에 잘못 들어가지 않도록, 이후의 층 보정은 마지막에 적용한다.
- 30층 이후 추가 체력 배율은 `1 / (1 + 0.02 × (층 - 30))`, 추가 공격 배율은 `1 / (1 + 0.01 × (층 - 30))`다. **전체 체력/공격이 감소한다는 뜻이 아니다.** 층별 레벨 상승으로 체력·공격·방어·속도가 계속 증가하므로, 추가 배율의 중복 증가만 억제한다. 같은 종류의 깊은 층 적 능력치가 계속 증가하는지 검증한다.
- 권장 플레이어 레벨은 해당 층 곡선의 플레이어 레벨에 메인 구간의 준비 보정을 더한다. UI에 적 곡선 레벨을 그대로 플레이어 레벨로 표시하던 문제도 수정했다. 추천은 입장 제한이 아니다.

5층마다 등장하는 보스는 연격형·후열 견제형·연타형의 공통 게임용 패턴을 순환한다. 큰 공격은 모두 예고하며, 후열 견제는 제자리 원거리 연출이다. 보스는 체력50%/25%에서 기존 각성:강타 규칙(70%/100%)을 사용한다. 기존 기술 순서와 행동 게이지는 유지하며, 점혈·방어·회피로 대응할 수 있다. 전환 문구는 비무대용 공통 연출이며 원작 사건/대사를 추가하지 않는다.

## 같은 조건의 전후 비교

기준 커밋 `5f37f3a`, 시드301~400 각100회. 기존 `BalanceSimulation.BotLevel`의 구간별 준비 수준, 시작 장비/무료 호흡법, 동료 무장비, 숙련·인연·수련 투자/소모품/합공 없음이다. 검증용 추가 레벨은 생략한 장비 투자를 대신하는 기존 조건이며 실제 유저의 강제 입장 레벨을 뜻하지 않는다. 각 행 내 전후의 파티 레벨·구성·장비·명령 정책은 같다. 행동 수는 아군 한 명이 명령을 내린 횟수다.

| 의뢰 | 평균 아군 행동 전→후 |
|---|---:|
| 철각비마대 척후 격퇴 | 10.0 → 20.9 |
| 저잣거리 자객 소탕 | 8.8 → 30.9 |
| 독사굴 버티기 | 10.6 → 41.1 |
| 혈마대 잔당 추격 | 16.9 → 62.7 |
| 살귀대 정찰조 제압 | 19.6 → 62.0 |
| 살룡대 잔당 추적 | 33.7 → 51.5 |
| 십삼혈 잔당 수색 | 27.6 → 49.0 |

모든 의뢰는 이 준비 파티로100/100회 성공했다. 독사굴은 평균 적 행동3회에서18회로 늘어 생존 목표를 실제로 수행했다. 초기 의뢰의 전투 수치는 동일하다.

| 비무대 | 파티 레벨 | 평균 아군 행동 전→후 |
|---|---:|---:|
| 1층 |10|10.9 → 12.7|
| 5층 |15|12.0 → 24.5|
| 15층 |29|13.9 → 43.0|
| 24층 |40|14.8 → 40.7|
| 25층 |42|18.9 → 51.5|
| 30층 |46|27.6 → 68.1|

초기층의 과도한 순간 피해는 줄이고 중간층 전투의 내구도·전조 대응 비중을 높였다. 성공률을 특정 값에 억지로 맞추는 대신, 준비된 파티의 통과 가능성·전투 길이·생존·성장 효과를 함께 본다.

## 별도 표본과 성장 검증

선정에 쓰지 않은 시드701~800, 각100회에서도 의뢰12개와 각 층 권장 준비 수준의 탑 보스5/15/25/30/35/40/50/60층은 모두100회 성공했다. 전조 대응을 제외하고 회복/해독/공격 정책은 같은 파티와 비교했다.

| 층 | 대응 시 / 무시 시 평균 종료 체력 |
|---|---:|
| 15층 |95.0% /54.9%|
| 25층 |96.9% /78.4%|
| 30층 |91.4% /69.7%|
| 35층 |88.9% /64.4%|
| 60층 |94.9% /49.7%|

현재의 기준 플레이어가 전조를 잘 대응했는데도 일정 비율로 반드시 패배하도록 맞추지 않는다. 이전 탑 테스트의 무장비 곡선 레벨·승률55~95% 상한은 최신 메인 준비 수준과 맞지 않아 교체했다. 대신 올바른 준비 수준의 통과 하한과 행동 수 상한, 전조 대응 시 생존 이득, 성장 전후 비교를 추가했다. 의뢰 테스트도 실제 개방 시점(기준 스테이지 돌파 후)의 동료/무공을 사용하도록 고쳤고 통과 하한은8/20에서17/20으로 높였다.

고정Lv46에서도 투자 차이를 따로 측정했다. 수련 시절 세트 전원 착용·부위+10·희귀까지 개방은 비교용 가정이며 획득/강화 비용의 경제성 검증이 아니다.

| 새 탑 | 시작 장비 / 수련 세트+10 성공 |
|---|---:|
| 40층 |100/100 /100/100|
| 44층 |100/100 /100/100|
| 45층 |0/100 /100/100|
| 49층 |99/100 /100/100|
| 50층 |0/100 /100/100|
| 55층 |0/100 /100/100|
| 60층 |0/100 /65/100|

이전 같은 +10 파티는49·50층 모두0/100이었다. 새 일반층은 상대적으로 완만하고, 보스층은 장비 투자와 전조 대응을 요구한다. 무장비 고정 레벨로 무한히 진행할 수 있도록 만들지는 않았다. 50층의 평균 행동 수는 +10파티74.1회로 과도한 장기전도 함께 제한했다.

`SideContentSimulation`, `SideContentBalanceTests`, 기존 의뢰·탑·보스 단계·보상 검증을 사용한다. 별도40회 표본(901~940)으로 의뢰 제한, 1~60층 전투 길이, 전조 대응 효과, 40~50층 성장 효과를 회귀 검사한다. Unity/Android 실제 조작·연출은 클라우드에서 실행하지 못한다.

## 최종 검증 결과

관련 검사65개 통과. 동일 HEAD를 별도 경로에 내보낸 변경 전 전체 검사는743개 중734개 통과·9개 실패, 변경 후는772개 중768개 통과·4개 실패다. 새 실패는 없다. 남은 항목은 메인 전체 스테이지 봇 검증, 초반 경제/진행, 일반27단계 전투 길이, 필수 승급의 위험/보상 검사다. 이 작업에서 그 기준이나 메인 수치를 변경하지 않았다. UI 및 UI 테스트 소스 컴파일도 통과했으며, 기존 미사용 필드 경고1개는 남아 있다.

## 원격 변경 병합 후 확인

위 표본과 전체 검사 결과는 원격 병합 전 기준이다. 이후 일반 적 체력 감소와 스테이지별 공격·방어 완화 변경을 병합했으며, 의뢰·비무대에도 공유 보정이 적용된다. 생존 의뢰는 메인 생존전과 동일하게 체력 감소에서 제외한다. 병합 후 관련 검사65개와 UI 소스 컴파일을 다시 통과했다. 전조 대응 검사는 종료 체력 개선과 실제 누적 피격 피해5% 이상 감소를 함께 확인하며, 5개 보스 층에서 모두 통과했다.
