# 무협 UI 스타일

## 방향

큰 인물 일러스트와 크기가 다른 메뉴 카드로 시선을 안내한다. 먹빛 바탕, 옅은 청옥색, 오래된 금색, 주홍색 인장을 사용한다. 기존 산수화와 인물 아트를 재사용하며, Android 세로 화면과 안전 영역을 기준으로 구성한다.

## 공통 스타일

- `UiFactory`: 팔레트, 버튼의 눌림·비활성 상태, 얇은 테두리와 강조 모서리, 텍스트 그림자, 경험치 표시를 공유한다.
- 제목은 사용 가능한 명조 계열 시스템 폰트를 우선 사용한다. 해당 폰트가 없으면 기존 한글 폰트로 표시한다. 본문은 고정 크기와 여유 있는 줄 간격을 사용한다.
- `WuxiaGlyph`: 검·산문·두루마리·동전·탑 등의 선형 아이콘을 uGUI 메시로 그린다. 별도 이미지가 없는 메뉴에도 아이콘이 표시된다. 장식 요소는 터치를 가로채지 않는다.
- 하단의 다섯 탭은 아이콘, 글자색, 상단 표시선으로 선택 상태를 함께 나타낸다. 같은 기호와 색상 규칙을 무공·행낭·뽑기·기록의 제목에도 사용한다.

## 강호 로비

상단 상태 표시 → 게임 제목 → 인물과 우측 보조 메뉴 → 대화 → 다음 여정 → 활동 카드 → 하단 탭 순서로 읽는다.

우측에는 일일 임무·의뢰·기연을 둔다. 하단 활동 카드에는 스테이지·승급·파티·탑·별 보상을 둔다. 다음 여정은 별도의 큰 카드와 주홍색 출전 버튼으로 강조한다. 잠금 조건·출전 준비·이어하기 등 기존 동작을 유지한다.

보유 배경이 없는 스테이지는 첫 산수화 배경을 재사용한다. 초상화가 없는 경우 기존 인물 글자 표시가 유지된다. 배지 개수와 자원 표시는 저장 데이터에서 갱신한다.

## 기록 화면

상태창은 큰 카드, 도감·업적과 추억·세력은 두 열의 카드, 이야기·전승의식은 넓은 카드로 구성한다. 각 카드는 기존 상세 패널을 연다. 장식용 아이콘과 제목, 요약 정보를 구분한다.

## 검증

Unity API 참조 어셈블리로 Core 및 Game/UI 전체 소스의 컴파일을 검사했다. 이 검사는 Editor 실행·폰트 렌더링·터치·마스킹·애니메이션을 검증하지 않는다. 별도로 작성한 레이아웃 시안은 실제 Unity 실행 화면이 아니다.

Unity 2022.3.62f1에서 `BiRyeoDo > Setup Project` 후 Play 모드로 다음을 확인한다.

1. 9:16 및 길이가 긴 세로 화면에서 상단 안전 영역과 하단 탭이 가려지지 않는지 확인한다.
2. 인물 터치·자동 교체, 이름·경지·대사가 겹치거나 잘리지 않는지 확인한다.
3. 강호의 여덟 메뉴, 다음 여정·출전 준비·이어하기, 각 패널 닫기가 동작하는지 확인한다.
4. 다섯 하단 탭과 기록의 일곱 카드, 알림 배지, 보상 획득 후 자원 갱신을 확인한다.
5. 긴 스테이지명·동료 이름·큰 자원 수치·잠긴 여정·그림이 없는 인물 상태를 확인한다.
6. 명조 폰트가 있는 PC와 없는 Android 기기에서 한글 표시를 확인한다.
7. 뽑기 전 장식이 결과 표시 때 함께 사라지고, 게임을 재시작해도 저장 상태가 유지되는지 확인한다.
