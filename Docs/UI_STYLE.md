# 무협 UI 스타일

## 방향

큰 인물 일러스트와 크기가 다른 메뉴 카드로 시선을 안내한다. 먹빛 바탕, 옅은 청옥색, 오래된 금색, 주홍색 인장을 사용한다. 기존 산수화와 인물 아트를 재사용하며, Android 세로 화면과 안전 영역을 기준으로 구성한다.

## 공통 스타일

글자 크기·줄바꿈·스크롤의 최신 기준과 전체 화면 점검 항목은 [가독성 기준](READABILITY.md)을 따른다.

- `UiFactory`: 팔레트, 버튼의 눌림·비활성 상태, 얇은 테두리와 강조 모서리, 텍스트 그림자, 경험치 표시를 공유한다.
- 제목은 사용 가능한 명조 계열 시스템 폰트를 우선 사용한다. 해당 폰트가 없으면 기존 한글 폰트로 표시한다. 본문은 고정 크기와 여유 있는 줄 간격을 사용한다.
- `WuxiaGlyph`: 검·산문·두루마리·동전·탑 등의 선형 아이콘을 uGUI 메시로 그린다. 별도 이미지가 없는 메뉴에도 아이콘이 표시된다. 장식 요소는 터치를 가로채지 않는다.
- 하단의 다섯 탭은 아이콘, 글자색, 상단 표시선으로 선택 상태를 함께 나타낸다. 같은 기호와 색상 규칙을 무공·행낭·뽑기·기록의 제목에도 사용한다.

## 강호 로비

상단 상태 표시 → 게임 제목 → 인물과 우측 보조 메뉴 → 대화 → 다음 여정 → 활동 카드 → 하단 탭 순서로 읽는다.

우측에는 일일 임무·의뢰·기연을 둔다. 하단 활동 카드에는 스테이지·승급·파티·탑·별 보상을 둔다. 다음 여정은 별도의 큰 카드와 주홍색 출전 버튼으로 강조한다. 잠금 조건·출전 준비·이어하기 등 기존 동작을 유지한다.

보유 배경이 없는 스테이지는 첫 산수화 배경을 재사용한다. 초상화가 없는 경우 기존 인물 글자 표시가 유지된다. 배지 개수와 자원 표시는 저장 데이터에서 갱신한다.

## 기록 화면

상태창은 큰 카드, 도감·업적과 추억·세력은 두 열의 카드, 이야기·전승의식은 넓은 카드로 구성한다. 각 카드는 기존 상세 패널을 연다. 장식용 아이콘과 제목, 요약 정보를 구분한다.

## 전투 화면

`BattleScreen.Hud.cs`는 표시 계층을 담당하고 `BattleScreen.cs`는 기존 입력·전투 재생 흐름을 유지한다. 배치는 안전 영역 안의 세로 화면을 기준으로 한다.

- 상단: 스테이지·속도·포기, 초상화와 이름이 있는 일곱 칸의 행동 순서, 적 정보 띠 순서다. 현재 순서는 금색, 아군·적군은 청옥·주홍 표시선으로 구분한다. 이름과 순번도 함께 표시한다.
- 적 정보 띠: 강타를 준비하는 적을 우선 보여 주고, 그렇지 않으면 보스를 보여 준다. 체력·다음 기술·현재 단계와 실제 단계 전환 체력 지점을 표시한다. 강타 기술과 대상 이름은 밝은 주홍색으로 강조한다.
- 중앙: 기존 6×3 진형과 측면 전투 인물을 사용한다. 옅은 바닥 표시와 발밑 원으로 공간을 나누고, 현재 인물·공격 대상에는 금색 테두리를 둔다. 사거리 밖·강타 대상·아군 선택 가능 여부는 글자로도 표시한다.
- 하단: 전황, 현재 인물과 내공·기세, 네 무공 카드, 공격·방어·운기·아이템·합공 순서다. 필살기는 현재 인물 오른쪽의 금색 카드다. 무공 이름과 비용·재사용 대기 표시는 별도 글자 영역을 사용한다. 아이템·합공 메뉴는 두 줄의 선택 카드로 전환한다.
- 인물과 아이콘은 기존 아트를 사용하며, 없는 아이콘은 검·방패·연꽃 등의 선형 그림으로 대체한다. 스테이지 배경이 없으면 공통 산수화 배경을 사용한다.
- 적 체력과 단계 표시는 재생 중인 이벤트를 따라 갱신해 뒤의 피해 결과가 먼저 표시되지 않도록 한다. 장식과 상태 표시는 터치를 가로채지 않는다.

설계 참고: [옥토패스 트래블러 II](https://store.steampowered.com/app/1971650/)의 행동 순서 구분, [페르소나 5 더 로열](https://store.steampowered.com/app/1687950/)의 주요 명령 강조, [슬레이 더 스파이어](https://store.steampowered.com/app/646570/)의 적 행동 의도 표시. 기존 아트와 먹색·청옥·금색·주홍 팔레트로 표현한다.

## 검증

Unity API 참조 어셈블리로 Core 및 Game/UI 전체 소스의 컴파일을 검사했다. 이 검사는 Editor 실행·폰트 렌더링·터치·마스킹·애니메이션을 검증하지 않는다. 별도로 작성한 레이아웃 시안은 실제 Unity 실행 화면이 아니다.

Unity 2022.3.62f1에서 `BiRyeoDo > Setup Project` 후 Play 모드로 다음을 확인한다.

1. 9:16 및 길이가 긴 세로 화면에서 상단 안전 영역과 하단 탭이 가려지지 않는지 확인한다.
2. 인물 터치·자동 교체, 이름·경지·대사가 겹치거나 잘리지 않는지 확인한다.
3. 강호의 여덟 메뉴, 다음 여정·출전 준비·이어하기, 각 패널 닫기가 동작하는지 확인한다.
4. 다섯 하단 탭과 기록의 일곱 카드, 알림 배지, 보상 획득 후 자원 갱신을 확인한다.
5. 긴 스테이지명·동료 이름·큰 자원 수치·잠긴 여정·그림이 없는 인물 상태를 확인한다.
6. 명조 폰트가 있는 PC와 없는 Android 기기에서 한글 표시를 확인한다.
7. 뽑기 전 장식이 결과 표시 때 함께 사라지고, 게임을 재시작해도 저장 상태가 유지되는지 확인한다.

### 전투 확인 항목

Unity API 참조 어셈블리를 사용한 전체 Core/Game 컴파일과 별도 HTML 배치 시안을 확인한다. 시안은 Unity 실행 캡처가 아니며 폰트 줄바꿈·클리핑·터치의 최종 검증은 Play 모드와 Android 기기에서 한다.

1. 9:16, 9:19.5 화면에서 상단 안전 영역, 무공 네 칸, 보조 행동 다섯 칸과 속도·포기 터치 영역을 확인한다.
2. 혼자 싸우는 초반과 네 명의 파티, 일반 적·정예·보스가 섞인 진형을 확인한다. 인물 그림이 없을 때의 글자 대체도 확인한다.
3. 공격→적 선택→취소, 사거리 밖 대상, 전체 공격, 아군 회복→선택→취소, 아이템·합공 선택과 길게 누르기 설명을 확인한다.
4. 내공 부족·재사용 대기·아이템 없음·필살기 미장착·기세 부족·해금 전 합공의 표시와 비활성을 확인한다.
5. 강타 예고·그 대상·중단·방어·회피·상태 이상과 50%/25% 단계 전환(퇴각 보스는 실제 기준선)을 확인한다. 단계 전환은 행동 게이지를 지연시키지 않는다.
6. 다단 공격·출혈·중독·화상·퇴각에서 적 정보 띠와 인물 체력바가 같은 피해 순서로 변하는지 확인한다.
7. 긴 무공명·단계명·시험 진행도, 큰 체력 수치, 패배 후 재도전·승리·전투 간 정비·이야기 창 뒤 명령 복귀를 확인한다.
