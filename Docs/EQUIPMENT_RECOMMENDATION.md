# 추천 장비

장비 화면에서 선택한 인물의 그림 위 「추천 장비」를 누르면 6부위를 함께 평가하고 바로 장착합니다. 다른 인물의 장비는 해제하지 않으며 은자·재료·여분 장비를 소비하지 않습니다.

## 착용자 표시

목록의 장비 카드 아래에는 `"효룡" 장착 중`처럼 착용자 이름을 표시합니다. 선택한 인물 외의 착용자를 먼저 표시하며, 여러 명이면 `"효룡" 외 2명`으로 줄입니다. 장비 상세에는 모든 착용자 이름을 표시합니다. 남는 복사본이 있으면 다른 인물이 착용 중인 종류도 선택한 인물에게 장착할 수 있습니다.

## 추천 기준

`EquipmentRecommendation`은 다음 입력을 사용합니다.

- 선택한 인물의 현재 장비와 아무도 착용하지 않은 복사본. 비류연 전용 제한과 동일 장신구 중복 장착 금지를 지킵니다.
- 현재 레벨·인연·수련·검룡위·장착 심법, 실제로 사용할 수 있는 무공. 주인공은 장착한 무공의 숙련/변초, 동료는 현재 레벨에 배운 무공만 사용합니다.
- 부위별 강화·등급 개방·장비별 한계돌파와 강화 상한. 등급이 미개방이면 강화는 0으로 평가하되 기본/돌파 효과는 적용합니다. 자동으로 등급을 개방하거나 강화하지 않습니다.
- 세트의 현재 누적 보너스, 치명타 확률 상한과 경지 보너스까지 반영한 최종 능력치.

평가값은 예상 공격/지원 효율과 생존력의 조합입니다. 무공 위력·타수·사거리·전체기·상태 이상·회복·보호·재사용·내공·필살기 기세를 고려하고, 속도는 행동 빈도로 평가합니다. 내공은 8차례 동안의 재사용 기반 평균 소비량으로 지속성을 추정합니다. 치유는 대상 최대 체력에 비례하므로 시전자 공격력/치명타로 회복량이 증가한다고 가정하지 않습니다. 생존력 가중치는 일반 공격형 0.55, 치유형 0.85, 파티 보호형 1.05입니다.

## 조합 탐색과 적용

후보 곱이 60,000 이하이면 전부 비교합니다. 큰 보유 목록은 각 부위의 상위 조합 64개를 남기는 탐색에 현재 장비·보유 세트 조합을 더하고, 부위 교체와 장신구 두 칸의 교환을 두 차례까지 개선합니다. 세트가 완성되기 전에는 약한 장비도 조합 후보로 평가합니다. 현재 장비도 최종 후보에 남겨 평가값이 낮은 조합으로 바뀌지 않게 합니다. 동점이면 빈칸을 채우고, 같은 착용 수에서는 기존 부위를 유지합니다.

전투의 적 구성·수동 조작에 따라 최선이 달라지므로 모든 상황에서의 수학적 최적해를 보장하지 않습니다. 큰 목록은 탐색 범위를 제한합니다. 추천은 하나의 종합 기준이며 별도 재화로 기능을 해금하지 않습니다.

적용 직전에 수량·전용 제한·부위·중복을 다시 검사한 뒤 선택한 인물의 목록과 부위 배정만 함께 갱신합니다. 강화 단계와 개방 등급은 그대로 유지합니다. 새로운 세이브 필드는 없습니다.

## 검증

`EquipmentRecommendationTests`는 자원/타인 장비 보존, 6부위 장착, 여분 복사본, 전용 제한, 장신구 강화/상한/개방, 역할 차이, 세트 시너지, 장착 무공 변경, 전체 장비 목록에서의 반복 적용과 착용자 이름을 검증합니다. 관련 Core 테스트 54개가 통과했습니다. 전체 Core 검사(추가 무공 회귀 테스트 직전)는 742개 중 732개 통과, 기존 실패 10개 유지이며 새 실패는 없습니다.

모든 장비를 보유한 .NET 8 검사에서 인물당 추천 계산은 약 150~180ms였습니다. 실제 Unity/Android UI와 터치 성능은 별도 검증이 필요합니다. UI 소스와 UI 테스트는 Unity 참조를 사용한 컴파일만 확인했습니다.
