# Standing 입화 추가: 스토리 인물 4조

경로: `Assets/_Project/Resources/Art/Standing/`. 기존 파일과 1~3조를 보존하고 아래 7명 및 Unity 메타 파일을 추가했다. 모두 1024×1536 RGBA PNG다. Battle SD와 게임 코드는 변경하지 않았다.

아래 표의 원작 단서와 게임용 디자인 표현을 구분한다. 구체적인 얼굴형·표정의 과장·색조·복식 세부·소품 배치는 원작 단서에 명시하지 않은 한 창작이다. 도굴군과 허주운의 숫자 나이, 임덕성의 모피와 갑옷 등을 새로운 원작 설정으로 확정하지 않는다.
