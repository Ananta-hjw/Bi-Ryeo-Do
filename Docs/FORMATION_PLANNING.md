# 자동 진형 배치

아군과 적 모두 현재 능력치와 사용 가능한 기술을 기준으로 앞·중간·뒷줄을 선택합니다. 전투 수치나 적 기술 순서는 변경하지 않으며, 수동 배치와 전투 중 고정된 자리는 그대로 유지합니다.

## 평가 순서

1. 현재 체력과 방어로 유효 체력을 구하고 공격·속도·치명타, 장착 무공의 위력·타수·내공·기세·재사용, 치유·보호 능력으로 전투 가치를 추정합니다. 적은 일반/저격 기술과 보스 단계의 공격 배율을 사용합니다.
2. 줄당 최대 3명, 앞줄부터 빈 줄 없이 사용하는 배치를 열거합니다. 기존 인물이 고정된 신규 동료 배치는 빈 줄을 허용하면서 고정 열을 지킵니다. 초기 집중 공격/저격 위험이 낮은 12개와 기본 역할 배치, 예비 방어선이 다른 후보를 남깁니다.
3. 실제 `InteractiveBattle` 복사본으로 검증합니다. 일반 공격은 가장 가까운 줄의 낮은 체력 비율 대상을 집중 공격하고, 저격은 가장 뒤를 노립니다. 사거리 2는 세 번째 줄에 닿지 않습니다. 내공·기세·재사용·상태 이상·회피·보호·구조·보스 각성이 실제 엔진대로 작동합니다.
4. 아군은 연속 전투에서 남는 자원과 기본 휴식 회복을 반영합니다. 별도 3개 난수 표본으로 추린 상위 8개를 9개 표본으로 재평가합니다. 통과한 전투 수, 생존 인원·체력·남은 공격/지원 가치를 함께 평가하며 나쁜 표본에도 가중치를 둡니다. 근소한 동점에는 기본 역할 배치를 선호합니다.
5. 적은 현재 아군에 대한 유효한 배치 중 위험 추정 상위 6개를 각각 3개 표본으로 짧게 평가합니다. 6명 이상인 적은 기존 능력치 기반 규칙으로 탐색량을 제한합니다. 양쪽 모두 우두머리라는 이유만으로 앞이나 뒤에 고정하지 않습니다.

## 예측 범위와 안전성

- 적 후보 예측은 최대 96행동/아군 명령 48회, 아군 연속 전투는 전투당 최대 384행동/명령 192회입니다. 제한에 도달하면 남은 상태로 평가하며 승리로 처리하지 않습니다.
- 적 평가의 전술 정책은 피해 효율·현재 전조·회복을, 아군의 보수적 정책은 약한 적 공격·전조 대응·위급한 치유를 사용합니다. 완벽한 조작에 의존하는 아군 배치를 줄이려는 구분입니다. 실제 플레이어 명령이나 실전 난수를 미리 읽지 않습니다.
- 예측용 상태는 복사합니다. 체력·내공·기세·게이지·상태 지속시간·재사용·보스 기본 능력치와 단계, 준비 중인 공격 대상은 원본을 변경하지 않습니다. 기술 정의는 엔진에서 변경하지 않으므로 공유합니다.
- 장비/심법/숙련/경지 등이 반영된 최종 능력치를 사용합니다. 앞으로 받을 경험치, 새 장비, 소모품 사용, 합공, 휴식 추가 보너스는 예측하지 않습니다. 최적 배치나 승리를 보장하는 탐색은 아닙니다.
- 이어하기는 이미 이긴 전투를 제외하고 저장된 체력·내공·기세로 계획합니다. 캐시는 적 정의·기술·단계·시험 규칙·자원까지 구별합니다. 적 배치 배열은 복사해서 반환합니다.

## 검증

`FormationTests`와 `FormationPlanningTests`는 전후열 위협, 사거리 2, 원본 상태 보존, 결정성, 수동 고정, 신규 동료, 캐시 무효화·반환값 격리, 이어하기를 검증합니다. 후반 24·30·31단계는 예측에 쓰지 않은 난수 901~940에서도 준비된 기본 파티로 각각 38/40·40/40·39/40회 승리했습니다.

29단계의 기본 파티 난이도 문제는 여전히 남아 있습니다. 이 변경에서 적 능력치나 테스트 합격 기준을 낮추지는 않았습니다.

.NET 8 개발 환경에서 해당 단계들의 최초 배치 계산은 대략 80~460ms였으며, 첫 JIT 실행은 약 1초였습니다. 입력이 같으면 캐시를 재사용하며, 반복 조회는 약 0.3~0.4ms였습니다. Unity/Android 실기기 성능과 화면 조작은 별도 검증이 필요합니다.

전체 Core 테스트는 725개 중 715개 통과, 기존 실패 10개 유지(새 실패 없음). 자동배치 관련 38개 테스트와 Unity 참조 기반 UI 코드 컴파일은 통과했습니다. 기존 실패에는 일반 27단계의 전투 길이, 29단계 및 의뢰·탑·승급·초반 경제 관련 검증이 포함됩니다. Unity 실행 검증 결과를 뜻하지는 않습니다.
