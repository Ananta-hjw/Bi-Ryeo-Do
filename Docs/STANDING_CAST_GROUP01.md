# Standing 입화 추가: 스토리 인물 1조

경로: `Assets/_Project/Resources/Art/Standing/`. 기존 입화는 보존하고 아래 7명과 Unity 메타 파일을 추가했다. 1024×1536 RGBA PNG이며 기존 Standing의 전신 입화 화풍을 참고했다. Battle SD는 변경하지 않았다.

원작의 외형·성격과 게임용 디자인 선택을 구분한다. 구체적인 얼굴형, 체격, 세부 색조와 소품 배치는 아래에 원작 단서로 명시하지 않은 한 창작이다. 기존 인물과 얼굴을 복제하지 않고 표정·실루엣·재질로 구분한다.
