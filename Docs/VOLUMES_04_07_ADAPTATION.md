## 본편 연결

- 4권 / 스테이지 10: 홍란이 자기 연주 허락을 구하는 장면, 한 달의 기관·생문 준비,
  진령 제압 → 다섯 경보 → 나예린 귀환 → 진령 부축 틈 탈출의 순서를 교정했다.
  독한녀 직접 소탕과 나예린 처치는 원작과 다르므로 기존 3전투를 4/6/8 적행동 버티기로 바꿨다.
  경계 읽기를 전투 조작으로 재현한 것은 게임 각색이다. 효룡의 정보 제공·접선은 독자 선공개이며
  비류연 일행이 간자의 정체를 알아내는 추리 정답으로 사용하지 않는다.
- 4권 / 스테이지 11: 검후 무공을 훔칠 필요가 없다는 주장의 검증과 비류연의 관계 기대를 구별했다.
  연인 약속이 아니다. 천서각 열람 거절 → 정식 승급 결심 → 조부 모욕과 검성전 약속을 연결했다.
  대사형·묵룡환, 준호의 불완전한 칠매검 성장과 기존 승급 전투는 유지한다.
- 5권 / 스테이지 12~13: 홍란과 정식 사제 관계를 새로 확정하지 않는다.
  당철영이 동전 세 개를 막는 성장, 검후전의 절제·도성전의 계산·검성전의 전력 충돌을 구분했다.
  검성전 다음 날 삼성대전 결승, 익숙한 곡에 흔들린 위지천·연주 중단·봉황무 회피·뇌령사 방어를 잇는다.
  세 부문 우승자를 직접 꺾은 종합 우승이 아니다. 내기는 염도의 보고로 알고 정산한다.
  사과는 검후처 의심에 대한 것이며 실제 301호 침입과 별개다. 무단 입맞춤·발검 반응을 누락하지 않는다.
- 6~7권 / 스테이지 14: 기존 번호를 유지하며 8전투를 11전투로 확장했다.
  새해 비류연의 2학년과 주작단의 4학년을 구분하고, 표선 우정·수중 구조·수뢰비 지원·적웅채 협상·현검자 깨달음·숙소 엄호를 이어 배치했다.
  초상화 네 표적, 효룡의 귀환과 도법 경고, 두 번의 모용휘 부상·불안정한 금제,
  변장 두 번으로 벌어 준 이레, 준호 아홉 시진 뒤 일곱 명 열두 시진의 공동 돌파를 분리했다.
  두 번째 갈효봉 공방은 6 적행동 엄호다. 쌍살 퇴각 뒤 심뢰·짧은 정신 회복·몸의 한계·마지막 ‘효룡’ 호칭·배웅을 컷신으로 마무리한다.
  형의 이별을 별도 처형 선택이나 추가 처치 보상으로 만들지 않았다.
- 7→8권 / 스테이지 14 끝~15 도입: 적의 흔적 삭제 → 증거 부족 → 신병 요구 → 마진가의 거부 → 친구들의 합류 → 혼자 길을 막는 비류연으로 연결한다.
  실제 철각비마대 대결은 기존 15의 8권 회상으로 남긴다.

원문의 호칭 충돌(4권 친손녀 / 9~10권 딸)은 재분석 캐릭터 표도 명시한다.
게임은 기존 후속권 연속성에 맞춘 나백천의 딸 표기를 유지했다.
사부 신원·홍과 장홍의 동일성·대공자와 ‘그분’의 동일성을 이 구간에서 확정하지 않았다.
