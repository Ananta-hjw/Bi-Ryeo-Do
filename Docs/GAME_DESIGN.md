# 비려도 게임 디자인 (초안)

개인용 Android 싱글플레이 게임. 배포 계획 없음(저작권/스토어 심사 고려 불필요).
장르: 무협 + 턴제 전투 + 성장(환생형). 스토리는 사용자가 별도로 제공 → `StageDef.storyText`에 채운다.

## 레퍼런스 분석 (수련협객 스크린샷 4장)
| 화면 | 관찰한 요소 | 우리 구현 |
|---|---|---|
| 전투 | 세로 화면, 수묵화 배경, 상단에 `제N생`·스테이지명·스토리 한 줄, 중앙 적, 하단 주인공. 적 HP바(%), `보스 도전` 버튼, 초당 공격 횟수와 치명타율 표시 | `StageDef`(스토리/적/보스), 속도(Speed)=행동 빈도, 치명타. 실시간 대신 **행동 게이지 기반 턴제** |
| 전투(적 교체) | 같은 스테이지에 일반 몹(맷돼지 괴물)과 보스(백원왕), 처치 시 `+149`두 | `EnemyDef.dooReward/expReward`, `killsToBoss` 후 보스 해금 |
| 무공 | 무공서 아이템(구양진경, 태현비결 등) 컬렉션, 등급별 색/광채 | `MartialArtDef`, `SaveData.LearnedArts/EquippedArts` |
| 경영 | 객잔·전장 건물이 두(재화)를 자동 생산, 우측 `재산` 패널 | 1단계에서는 건물당 초당 두 생산(방치 수입) — 미구현 |
| 하단 탭 | 무공 / 경영 / 전투 / 기화 / 행낭 | `TabRouter` (패널 5개) |
| 공통 | `제N생` = 환생 횟수, 재화 `두` | `SaveData.Life`, `SaveData.Doo`, `Progression.Reincarnate` |

아트 느낌: 수묵화/먹 번짐 배경, 붉은 먹 글씨 강조, 두루마리형 라벨, 금색 엽전 아이콘.

## 핵심 루프
전투(적 처치) → 두·경험치 획득 → 무공 습득/강화·건물 투자 → 더 강한 스테이지/보스 → 일정 경지 도달 시 **환생**(제N생 증가, 영구 보너스) → 반복.

## 전투 규칙 (구현됨, `Core/BattleEngine`)
- 틱마다 각 유닛 게이지 += Speed, 1000 도달 시 행동. 동시 도달이면 게이지가 큰 쪽.
- 행동 시작: 쿨다운 -1, 내공 +10. 사용 가능한 무공 중 위력 최대를 사용, 없으면 기본 공격.
- 대상: 살아있는 적 중 HP 최저.
- 피해 = `Attack × Power × (크리티컬 ? CritDamage : 1) × 100/(100+Defense)`, 최소 1.
- 300행동 내 결판이 안 나면 무승부(플레이어 패배 취급).

## 성장 (`Core/Progression`, 수치는 임시)
- 필요 경험치 `50 × level^1.5`, 레벨당 HP+20 / 공격+3 / 방어+2 / 내공+5.
- 환생: 레벨 30 이상, 제N생마다 전 스탯 +10%. 두·습득 무공은 유지, 레벨/스테이지는 초기화.

## 로드맵
1. (완료) 코어 전투/성장 로직 + 테스트, 저장, 데이터 에셋, 탭 라우터, 셋업 스크립트
2. (완료) 전투 화면 UI: 헤더(제N생/두), 스테이지 제목·스토리, 적 HP바, 보스 도전, 플레이어 블록, 데미지 숫자, 5탭 바. 스프라이트 없이 단색 플레이스홀더로 동작 — 수묵 에셋은 `EnemyDef.portrait`/`StageDef.background`에 넣으면 적용
3. 무공 탭(습득/장착), 행낭 탭(아이템)
4. 경영 탭(객잔/전장 자동 수입, 오프라인 수익)
5. 기화(기연) 탭: 랜덤 이벤트/무공서 획득
6. 스토리 연출, 사운드, 밸런스 조정
