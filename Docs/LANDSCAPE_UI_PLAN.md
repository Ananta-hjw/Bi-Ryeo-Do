# 가로 화면 전환 계획

## 목표와 원칙

가로 화면의 넓이를 활용해 인물 선택·장비·수련을 한 화면에서 관리한다. 먹색·옥색·금색과 기존 인물 일러스트를 사용해 무협 분위기를 유지한다. 전투·성장 계산, 보상과 저장 데이터는 기존 Core 규칙을 재사용한다.

[클릭 가능한 화면 시안](UI/landscape-prototype.html)은 1단계 산출물이다. 인물 선택, 탭 전환, 장비 부위·후보 선택을 확인할 수 있다. 표시 수치와 장비는 배치 검토용 예시이며 실제 게임 데이터와 연결되지 않는다. 다른 메뉴 버튼은 연결 위치를 안내한다.

## 단계와 완료 기준

| 단계 | 작업 | 완료 기준 | 현재 상태 |
|---|---|---|---|
| 1 | 구조 설계·클릭 시안 | 현재 메뉴의 이전 위치, 인물별 기능 범위, 화면 구성과 검증 항목 문서화 | 완료 |
| 2 | 가로 기반·메인 | 가로 방향, 안전 영역 갱신, 가로 메인·내비게이션 구현 | 구현 완료 · 기기 검증 필요 |
| 3 | 협객 관리 통합 | 선택 인물을 유지하며 상태·장비·무공·인연을 조회·조작 | 구현 완료 · 기기 검증 필요 |
| 4 | 전투·스토리 | 전장·명령·행동 표시·대화·결과창의 가로 배치와 연출 확인 | 구현 완료 · 기기 검증 필요 |
| 5 | 전체 화면·검증 | 나머지 메뉴·안내창 대응, 데이터·입력·화면 비율 회귀 확인 | 구현 완료 · Unity/Android 실행 검증 대기 |

순서대로 구현하며 각 단계의 변경과 검증 결과를 보고한다. 시안 작성만으로 게임 방향 설정을 바꾸지 않는다. 부분 전환 중인 화면은 기존 진입 경로를 유지하고, 기능이 실제로 연결된 뒤 중복 경로를 정리한다.

## 화면 구성

### 강호 메인

- 상단: 인물·두·주요 재료. 하단: 강호 / 협객 / 무공 / 행낭 / 기록의 공통 이동 메뉴.
- 왼쪽 약 40%: 대표 인물 일러스트·이름·검룡위.
- 오른쪽: 출정, 협객, 무공, 행낭, 기록의 주요 카드. 의뢰·탑·편성은 보조 바로가기.
- 기존 뽑기는 보조 바로가기로 옮기되 기존 기능과 재화 확인·결과 흐름은 유지한다.

### 협객 관리

- 상단 인물 초상화 선택줄. 영입한 인물만 조작 가능하다.
- 왼쪽 약 25%: 선택 인물 일러스트·레벨·경지·핵심 정보.
- 오른쪽 약 75%: 상태 / 장비 / 수련 / 무공 / 인연 탭과 상세 내용.
- 인물을 바꿔도 현재 탭·장비 부위를 유지한다. 선택 장비는 새 인물에 맞게 갱신한다.
- 장비: 착용 부위 / 보유 목록 / 선택 장비 상세를 나란히 표시한다. 세트 효과는 상단에 한 번만, 돌파 고정 옵션은 하늘색으로 표시한다.
- 강화 버튼·상한·적용 강화는 현재 착용 장비에, 보유 재료·두·개방 등급은 별도 자원 띠에 표시한다. 미개방·돌파 상한·재료 부족 사유를 분명히 표시한다.
- 수련: 현재 단계·능력 보너스·다음 효과·비용·인연 상한을 한 화면에 표시한다.
- 주인공에게 동료 수련을 적용하지 않는다. 주인공 수련 영역은 기존 경험치·검룡위·심법으로 안내한다.
- 주인공 무공은 습득·장착·숙련, 동료 무공은 고유 기술·레벨 해금·수련 효과를 다룬다. 주인공 인연 탭은 동료 인연 목록, 동료 인연 탭은 해당 인물의 효과·합공을 보여준다.

## 현재 기능과 이전 위치

| 현재 경로 | 새 경로 | 구현 관련 파일 |
|---|---|---|
| 기록 → 상태창 → 동료 장비 | 협객 → 인물 → 장비 | `StatusPanel`, `RecordScreen`, `Inventory`, `Gear` |
| 무공 → 동료 수련 | 협객 → 인물 → 인연 → 동료 수련 | `CompanionPanel`, `CompanionTraining`, `Bonds` |
| 무공 → 무공·심법 | 무공 및 협객의 개인 무공 조회 | `MartialArtsScreen`, `InnerArtPanel`, `Mastery` |
| 강호 → 파티 편성 | 강호 편성 바로가기·협객에서의 출전 정보 | `WorldScreen`, `Roster`, `Formation` |
| 기록 → 세력·객잔 / 추억 | 기존 기록 유지, 관련 인연에서 연결 | `FactionPanel`, `MemoryPanel` |
| 하단 뽑기 | 강호 보조 바로가기 | `GachaScreen`, `MainScreen`, `TabRouter` |

## 구현상 주의점

- 전환 전 `MainScreen`은 1080×1920, 너비 기준 CanvasScaler를 사용했고 `ProjectSetup`은 Portrait를 설정했다. 2단계에서 1920×1080 높이 기준과 양쪽 가로 방향 자동 회전으로 변경했다.
- 가로 기준은 1920×1080으로 잡고 16:9·20:9·4:3에서 확인한다. 창 크기·화면 방향·노치가 바뀌면 안전 영역을 다시 계산한다.
- 세로 화면의 정규화 앵커를 그대로 회전하면 글자·버튼·전장 높이가 부족하다. 공통 내비게이션, 모달, 읽기 영역과 전투를 각각 재배치한다.
- 새 협객 메뉴를 추가할 때 기존 `Tab` 정수의 참조와 알림 표시를 확인하고, 기존 메뉴를 여는 콜백을 새 경로에 연결한다.
- 장비 부족·다른 인물 착용·주인공 전용 장비·장신구 두 칸·부위별 강화·등급 개방 규칙을 유지한다.
- 전투의 원거리 제자리 공격, 근접 접근·복귀, 행동자 표시, 별·전리품과 성장 결과를 유지한다.

## 검증

- 인물·탭·장비 선택을 반복해도 상태가 섞이지 않아야 한다. 목록·상세·뒤로 이동의 선택과 스크롤을 확인한다.
- 장비 교체·강화·돌파·수련 전후의 실제 능력치·비용과 저장 재시작 결과를 확인한다.
- 미영입·빈 장비·최대 강화·재료 부족·인연 상한·주인공/동료의 기능 차이를 확인한다.
- 스토리·팝업 뒤 클릭 관통, 배속 전투, 결과 확인·진행 저장·재개를 확인한다.
- .NET Core 테스트와 Unity API 참조 컴파일은 로직·타입 검사다. 실제 Unity Editor/Android의 화면·터치·모션·노치는 별도 실행 검증이 필요하다.

## 1단계 확인 결과

- Playwright/Chromium으로 인물·탭·부위 유지, 부위별 후보 전환, 장비 상세 선택, 시안 버튼 안내와 주인공 수련 분기를 확인했다.
- 1920×1080, 1280×720, 2400×1080, 1440×1080에서 5개 관리 탭을 열어 최상위 화면의 가로·세로 넘침을 검사했다. 긴 상세 영역은 자체 스크롤을 사용한다.
- 사용 이미지 로드와 JavaScript 오류 유무를 확인했다. 이는 HTML 시안 검사이며 Unity 게임 화면 검증을 대신하지 않는다.
- 이 단계에서는 게임 코드·방향 설정·저장 데이터를 변경하지 않았다.


## 2·3단계 구현 결과

- `MainScreen`: 1920×1080 높이 기준, 가로 양방향 자동 회전, 강호/협객/무공/행낭/기록 내비게이션. 기존 Tab enum 값은 유지하고 협객만 끝에 추가했다.
- `SafeAreaLayout`: 화면 크기·노치 영역 변경을 감지해 안전 영역 앵커를 갱신한다. `ProjectSetup`과 런타임 모두 가로 방향을 설정한다.
- `LandscapeHome`: 기존 인물 일러스트·대사와 실제 저장 데이터를 표시한다. 출정·스테이지 목록·의뢰·탑·편성·뽑기·일일 임무·별·기연·승급·설정으로 연결했다.
- `CompanionScreen`: 영입한 인물 선택줄, 왼쪽 인물 정보, 오른쪽 상태/장비/수련/무공/인연 탭을 구현했다. 인물을 바꿔도 탭·장비 부위를 유지하며, 새 인물에 맞게 장비 상세를 갱신한다.
- 장비는 현재 착용/보유 목록/선택 상세를 나란히 표시한다. 착용 장비 안에 강화·등급 개방·해제와 부위 강화/적용/상한을 배치하고, 자원과 현재 세트 효과는 위쪽에 한 번만 표시한다. 목록 선택·강화 후 목록 스크롤 위치를 유지한다.
- 다른 인물·다른 장신구 칸에서 사용 중인 장비는 장착할 수 없다. 동료 목록에는 주인공 전용 장비를 표시하지 않는다. 장비 상세에는 돌파 옵션의 해금/잠김과 설명을 표시한다. 돌파·분해는 기존 행낭에서 진행한다.
- 동료 수련은 기존 인연 상한·비용·능력 보너스·3/6/10단계 해금 효과를 표시하고 실제 수련과 저장에 연결했다. 주인공 수련은 경험치·검룡위·심법 습득/장착/해제/강화로 구성했다.
- 주인공 무공 습득/장착/해제·변초 전환과 숙련 조회, 동료 고유 무공/레벨 해금/수련을 반영한 수치를 제공한다. 인연에서는 현재 보너스·다음 단계까지 점수·합공·수련 상한을 조회한다.
- 기존 무공/기록의 상태·수련 진입 경로는 병행 유지한다. 아직 이전하지 않은 메뉴는 `PortraitCompatibilityLayout`으로 원래 비율을 유지하는 임시 화면이다. 전투·스토리는 4단계에서 가로로 이전했고 나머지 메뉴는 5단계에서 재배치한다.

### 검증과 남은 확인

- Core 테스트: 553개 중 551개 통과. 기존 5스테이지 관련 밸런스 테스트 2개 실패가 유지됐다. 이번 Core 변경은 안내 문구이며 전투·성장 수식을 바꾸지 않았다.
- Unity API 참조로 Game/UI와 UI 회귀 테스트 소스 컴파일 성공. 기존 `WorldScreen.Row.Band` 미할당 경고 1개가 남아 있다.
- `LandscapeWorkspaceTests`: 화면 너비별 인물·부위 유지, 영입 제한, 주인공 전용 장비 제외, 주인공/동료 수련 분기, 재화·인연 상한과 안전 영역/기존 화면 비율 회귀 항목을 추가했다.
- 이 환경에는 Unity Editor가 없어 위 UI 테스트 실행과 실제 게임 렌더링·터치·저장 재시작을 확인하지 못했다. Unity Test Runner에서 UI 테스트 실행 후 Android에서 16:9/20:9/4:3, 양쪽 회전, 노치, 팝업 뒤 클릭 차단, 출정·귀환, 인물 변경과 강화/교체/수련의 실제 저장을 확인해야 한다.


## 4단계 구현 결과

- `MainScreen`의 전투 호스트를 원래 비율을 유지하는 임시 화면에서 안전 영역 전체를 사용하는 `BattleLandscape`로 전환했다. 기존 출정/승급/추억/귀환 콜백은 유지했다.
- 전장은 왼쪽 약 70%, 명령은 오른쪽 약 25%를 사용한다. 전장 위에 7칸 행동 순서와 보스 체력·단계·다음 행동을, 아래에 현재 행동자와 전황을 표시한다. 오른쪽에는 행동자 정보와 2열 명령을 배치한다.
- 기본 공격/필살기, 무공 네 칸, 방어/운기, 물품/합공을 모두 표시한다. 물품·합공 선택 모드도 같은 영역을 사용하며 취소 버튼을 유지한다. 명령 영역과 모든 전장 타일의 앵커가 겹치지 않도록 배치했다.
- 기존 근접 접근·타격·복귀, 원거리 제자리 공격, 게이지·상태와 함께 이동, 기울임 없는 연출을 유지했다. `BattleFigureFit`이 변경된 셀 크기에 인물 그림을 다시 맞추며 적의 좌우 반전은 유지한다.
- 전투 셀에서는 짧은 이름·각성 예고를 사용하고, 전체 이름과 자세한 예고는 전장 위 집중 정보와 인물/적 상세에서 확인한다.
- 스토리는 좌우 인물과 하단 대화창·이름표·읽기 진행·건너뛰기로 구성했다. 글자는 고정 크기로 페이지를 나눈다. 화면/안전 영역 변경은 읽고 있던 페이지의 시작부터 다시 나누며 읽지 않은 내용을 건너뛰지 않는다. 대사·서사 데이터는 변경하지 않았다.
- 개별 승리/스테이지 완료/레벨업/다음 전투 창은 왼쪽 요약과 오른쪽 상세 목록으로 분리했다. 별·경험치·두·파티 상태와 기존 보상 계산/확인/진행 저장 동작을 유지한다. 결과·스토리·재전투 선택·상세창은 전체 전투 영역에서 입력을 차단한다.
- 재전투 선택은 2열, 상세창은 제목·그림과 본문을 분리했다.

### 4단계 검증

- Unity API 참조로 Game/UI 및 신규 `LandscapeBattleTests`를 포함한 UI 테스트 소스 컴파일 성공. 기존 `WorldScreen.Row.Band` 경고 1개가 남아 있다.
- Core 테스트는 553개 중 551개 통과, 기존 5스테이지 밸런스 실패 2개 유지. 이 단계에서는 Core 전투·성장·보상 로직을 수정하지 않았다.
- 새 UI 회귀 테스트는 1440/1920/2400 너비의 명령/대상 영역 분리, 두 선택 모드의 버튼 접근성, 전체 화면 입력 차단, 실제 개별 보상 코루틴의 두 열 배치, 크기 변경 시 그림 비율·적 방향 유지를 검사하도록 작성했다. Unity Editor가 없어 실행하지 못했으며 컴파일만 확인했다.

## 관리 화면 정리

- 협객의 탭은 상태·장비·무공·인연 네 개다. 중복되던 주인공 심법 수련 화면을 제거하고, 동료 전용 수련은 인연 화면에서 두를 사용해 진행한다.
- 심법 습득·장착·강화는 무공 → 심법에서만 관리한다. 강화 재료 표시는 심득석으로 통일한다.
- 심법 목록은 한 행에 카드 두 개를 배치한다. 같은 행의 높이는 긴 설명에 맞춰 함께 조정하고, 각 카드 하단에 장착·강화 버튼을 둔다.

- 강호의 보조 메뉴 여덟 개(의뢰·무한 비무대·파티 편성·뽑기·일일 임무·별 보상·기연·승급 시험)는 4열 2행의 큰 카드로 표시한다. 이름·아이콘·짧은 설명을 분리하고, 알림 개수는 이름 옆 문장 대신 우측 상단 배지에 표시한다.

## 작은 버튼의 터치 영역 정리

- 공통 하단 메뉴 높이를 96에서 120 기준 픽셀로 확대한다. 메뉴 화면의 닫기는 하단 1.5~14%, 스크롤 목록은 16% 위에 두어 겹치지 않는다.
- 행낭의 일괄 분해·도움말·분류, 도감 및 세력의 분류 탭, 강호의 스테이지 목록·설정, 협객의 탭·부위·강화·해제 버튼을 확대한다. 상세창의 하단 조작과 전투 선택·정보창의 닫기도 함께 조정한다.
- 심법 카드의 장착·강화는 최소 행 높이의 27.5%를 차지하며 카드의 설명과 버튼 사이 간격을 유지한다. UI 회귀 테스트 소스에서 가로 폭별 버튼 높이와 목록 경계·겹침을 확인한다. 실제 기기 터치 검증은 Unity Editor와 Android 빌드에서 진행해야 한다.

## 강호 왼쪽 메뉴 통합

- 임무/보상 아이콘: 의뢰·일일 임무·별 보상·기연을 오른쪽 작은 선택창에 표시하고, 합산 알림 개수를 아이콘 배지에 표시한다.
- 도전 아이콘: 무한 비무대·승급 시험을 같은 방식으로 표시한다. 파티 편성은 독립 아이콘으로 즉시 연다. 묶음은 재선택·바깥 누르기·다른 화면 이동 시 닫힌다.
- 뽑기는 하단 강호·협객·무공·뽑기·행낭·기록의 여섯 탭으로 제공한다. 기존 경로 enum과 저장 데이터는 유지한다.
- 협객·무공·행낭·기록 카드는 2열 2행의 기존 큰 디자인(높이 20%)으로 복원한다. 왼쪽 아이콘과 초상화·이름·대사 영역은 분리한다.

## 뽑기 결과와 획득 목록

- 결과는 행마다 세 장의 카드로 표시한다. 1회·10회·50회 결과를 전부 표시하고 긴 목록은 스크롤한다. 같은 행은 긴 이름·효과에 맞춰 함께 높이를 조정하며, 새 뽑기를 시작하면 이전 카드와 스크롤 위치를 초기화한다.
- 왼쪽 등급·확률 버튼을 누르면 실제 `Gacha.Pool`의 아이템 목록을 연다. 아이콘·이름·기본 효과·세트 이름을 보여 주며, 미리보기는 두·인벤토리·뽑기 횟수를 변경하지 않는다.

## 협객 장착 요약

- 협객 → 장비는 현재 착용 중인 여섯 부위만 2열 카드로 보여 준다. 세트 효과는 상단에 한 번 표시하고, 각 카드에는 부위·장비 이름·등급·돌파·세트 이름·적용 효과를 분리해 적는다. 빈 부위는 미착용으로 표시한다.
- 부위 카드를 누르면 별도 장비 관리 창에서 교체 후보·강화 비용·해제·상세정보를 확인한다. 보유 장비 목록과 비용 설명은 기본 요약 화면에서 제외한다.
- 협객 → 무공은 실제 전투 유닛의 현재 무공만 보여 준다. 이름·자원·전투 효과·설명을 나누고, 주인공의 습득·장착·변초 관리는 무공 관리 화면으로 연결한다. 동료는 현재 레벨·수련으로 적용된 무공만 표시한다.

## 독립 장비 탭

- 하단 순서는 강호·협객·장비·무공·뽑기·행낭·기록이다. 장비 route는 기존 enum 끝에 추가해 기존 route 번호를 유지한다. 협객에는 상태·무공·인연만 남기고, 인물 정보의 장비 버튼은 같은 인물을 선택한 독립 장비 탭으로 연결한다.
- 장비 화면 왼쪽에는 `Art/Battle`의 캐릭터 그림과 여섯 착용 칸·실제 능력치를, 오른쪽에는 무기/방어구/장신구 분류와 3열 보유 목록을 배치한다. 그림이 없으면 Battle 기본 그림을 사용한다.
- 목록에서 장비를 선택하면 하단의 장착·해제·상세·강화 버튼이 갱신된다. 방어구는 선택한 아이템의 실제 부위, 장신구는 왼쪽에서 선택한 1/2번 칸을 사용한다. 착용 중 표식·현재 선택 테두리·다른 인물 사용 중 상태를 구분한다.
- 강화는 기존 부위 강화·등급 개방 로직을 사용하며 다음 비용과 재료 보유량을 먼저 표시한다. 기본 목록에는 효과·세트 이름만 표시하고, 긴 설명·돌파 옵션은 상세 창, 세트 단계별 효과는 세트 효과 창에서 확인한다.

## 기록 메뉴 스크롤

- 전장을 가로 화면 대부분으로 넓히고, 명령 10개를 하단 5열 2행에 배치한다. 첫 줄은 공격·일반 무공, 둘째 줄은 필살·합공·방어·운기·아이템이며 선택 모드에서는 아이템/동료와 취소를 같은 영역에서 표시한다.
- 상단 왼쪽은 현재와 다음 네 행동 순서, 오른쪽은 위험 적의 체력·단계 경계·다음 기술을 표시한다. 각성/강타 경고는 대응 안내와 줄을 나눈다. 행동 순서 초상과 적 경고 영역을 눌러 기존 상세 정보를 연다.
- 하단 명령 위에는 행동 인물·자원과 전황을 분리하며, 대상 선택 안내는 별도 띠에 표시한다. 공격 가능 색은 금색으로 안내를 일치시킨다. 필드의 이름·체력·상태·의도 텍스트는 고정 높이로 보정한다.
- 전투 규칙·피해·보상과 접근/타격/복귀 및 원거리 공격 구분은 기존 로직을 유지한다. Unity UI 소스 컴파일과 화면 비율별 회귀 테스트 코드를 점검하며 실제 렌더링/터치는 Unity Editor에서 검증해야 한다.


## 아이콘 확대

- 행낭 목록 132, 무공 목록 144, 장비 목록 160, 뽑기 결과 180 크기의 정사각형 아이콘을 사용한다. 3열 목록을 유지하면서 이름·설명 시작 위치와 최소 카드 높이를 조정한다.
- 협객 무공 요약에는 112 아이콘, 심법에는 112 문양을 표시한다. 심법 문양은 효과 계열에 따라 방패·검·번개 등으로 구분한다. 상세창 그림도 확대하고 본문과 분리한다.
- 전투 명령 아이콘은 80, 상단 바는 92, 하단 탭은 76으로 키운다. 이미지 비율은 유지하며 확대 영역이 설명과 겹치지 않는지 비율별 UI 회귀 검사에 포함한다.

## 개별 아이콘 그림 교체

- 무공 31개·심법 20개·아이템 281개를 각각의 무협풍 그림으로 연결한다. 실루엣·재질·효과를 구분하고, 등급 테두리는 기존 UI가 표시한다. 전투 명령과 메뉴에도 같은 화풍을 사용한다.
- 목록·상세창·전투는 같은 ID의 캐시된 그림을 공유한다. 원본 그림은 대체 경로로 남긴다. 매핑과 추가 방법은 `Docs/READABLE_ICONS.md`를 따른다.


## 배경과 이어지는 전투 명령

- 큰 하단 패널·구분선·명령별 사각 배경을 없애고, 열 개 명령을 한 줄의 104 크기 원형 아이콘으로 표시한다. 그림은 원형 마스크로 잘라 사각 바탕이 남지 않도록 한다.
- 배경은 전투와 조작 영역 아래까지 이어진다. 배경 종류에 의존하지 않는 검은 알파 그라데이션과 글씨 외곽선으로 대비를 확보한다. 인물·전황·선택 안내도 불투명 띠 없이 표시한다.
- 명령 버튼 전체는 투명한 넓은 터치 영역을 유지한다. 이름과 소모 자원은 아이콘 아래에 분리하고, 긴 무공 명칭은 마지막 이름을 표시하며 전체 설명은 기존 길게 누르기로 확인한다. 선택 취소는 X 문양으로 표시하고 사용 불가 상태는 밝기를 낮춘다.
- 무공/아이템/합공 선택 모드와 1440×960·1920×1080·2400×1080 기준에서 아이콘·글씨·터치 영역과 전장 분리를 검사하는 UI 회귀 코드를 갱신한다. 클라우드 검증은 소스 컴파일이며 실제 렌더링과 터치는 Unity에서 확인한다.
