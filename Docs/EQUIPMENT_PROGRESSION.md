# 장비 강화와 한계돌파

## 규칙

| 한계돌파 | 미돌파 | 1성 | 2성 | 3성 | 4성 | 5성 |
|---|---:|---:|---:|---:|---:|---:|
| 강화 상한 | +10 | +20 | +30 | +50 | +70 | +100 |
| 기본 효과 추가 | 0% | 5% | 10% | 15% | 20% | 30% |

한계돌파는 같은 장비 여분 1개를 사용한다. 착용자 수만큼의 장비는 남겨야 하며, 아무도 착용하지 않아도 본품 1개는 남긴다. 돌파는 아이템 ID별로 저장되므로 같은 종류를 입은 인물들은 돌파 단계를 공유한다. 세트 효과에는 강화·돌파 배율을 적용하지 않는다.

강화는 인물별 여섯 부위(무기·상의·하의·신발·장신구 1·2)에 저장한다. 교체·해제·분해 시 유지되며 다른 인물에게 전달되지 않는다. 장신구 하나를 해제해도 다른 칸의 장비와 강화가 이동하지 않는다. 현재 장비의 상한보다 높은 강화는 보관하고, 전투에는 `min(저장 강화, 장비 상한)`을 적용한다.

강화 증가량은 기본 효과에 +1~20 각 3%, +21~30 각 4%, +31~50 각 5%, +51~70 각 7%, +71~90 각 10%, +91~100 각 15%를 합산한다. 돌파 보너스도 같은 기본 효과에 합산한다. +100·5성은 기본 효과의 8.2배다. 기본 공격 +20% 장비라면 최종 공격 효과는 +164%다. 음수 효과도 기존처럼 같은 배율로 적용한다. 치명타율 상한 등 기존 전투 제한은 유지한다.

## 재료와 비용

공용 연마석(`gear_polish`)과 두를 쓰며 성공률은 100%다. 등급별 추가 비용은 없다. 다음 강화 단계 n에 필요한 연마석은 `1 + (n-1)/10`의 정수 부분, 두는 `100 + 20n + 2n²`다. +10까지 연마석 10개·2,870두, +100까지 연마석 550개·787,700두가 든다. 돌파에는 두·연마석을 사용하지 않는다.

연마석은 새 시작 꾸러미 30개, 전투 승리마다 2개(재전투·의뢰·탑·승급 포함), 일일 임무 보상마다 5개를 준다. 일반~전설 장비를 분해하면 기존 합성 재료에 더해 등급별 1~5개를 준다. 신화·초월 장비의 분해 제한은 유지한다. 마지막 돌파 장비를 분해하면 확인창을 거쳐 돌파만 사라지며 부위 강화는 남는다.

## 화면과 전승의식

행낭 장비 상세창에서는 한계돌파·분해를 한다. 목록은 장비 자체의 돌파 효과를 표시한다. 상태창의 인물·부위 선택창에서 장착·해제·부위 강화를 하고, 저장 강화·현재 적용·상한·비용을 함께 확인한다. 후보 효과는 그 부위에 장착했을 때 적용될 값으로 미리 표시한다.

전승의식의 마지막 조건은 **5성 비뢰도 낙뢰 보유**다. 나머지 다섯 조건은 유지한다. 진비뢰도는 신규 지급과 기존 보유 모두 처음부터 5성, 강화 상한 +100이다.

## 구버전 저장 데이터

저장 버전 2를 유지하고 `GearProgressionMigrated`, `GearSlots`, `GearBreakthroughs`를 추가한다. 기존 아이템 강화 n(최대 10)은 `min(n,5)`성으로 옮기고, 소모했던 중복 중 5개를 넘는 분량은 장비 여분으로 돌려준다. 당시 착용자의 해당 부위에 기존 강화 보너스(단계당 10%) 이상이 되는 최소 강화 단계를 저장한다(예: 기존 +10은 새 +30). 미착용 장비의 강화는 비류연의 해당 부위에 저장한다. 같은 부위의 기존 강화가 여러 개라면 가장 높은 수치를 보존한다. 이전은 한 번만 실행하며 기존 진비뢰도는 5성으로 정규화한다.

## 확인

강화 구간 경계, 여섯 상한, 다섯 돌파 보너스, +100 완주 비용, 부족한 재료·두의 원자성, 장비 교체 시 상한 적용·복원, 장신구 칸 독립, 동료별 강화, 기존 저장 이전·재이전 방지와 초월 지급을 Core 테스트로 확인한다. Unity 화면·터치·JSON 저장 왕복은 Unity에서 별도로 검증한다. 높은 강화까지 사용한 실제 전투 난이도는 기존 무강화 봇 결과만으로 보장하지 않는다.

클라우드 검증: 신규 성장 규칙 회귀 테스트 28개 통과(장비·동료·전승·슬롯 관련 71개 통과). 최신 원격 변경을 반영한 전체 Core 테스트는 390개 통과, 기존 초반 난이도 검사 2개가 동일하게 실패했다. Game/Core 및 Unity Editor용 UI·JSON 회귀 테스트 소스는 Unity API 참조 컴파일에 통과했다. Unity Editor·Android 실행과 JSON 런타임 왕복 테스트 실행은 이 환경에서 하지 못했다.
