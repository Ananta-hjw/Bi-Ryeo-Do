# 장비 강화와 한계돌파

## 규칙

| 한계돌파 | 미돌파 | 1성 | 2성 | 3성 | 4성 | 5성 |
|---|---:|---:|---:|---:|---:|---:|
| 강화 상한 | +10 | +20 | +30 | +50 | +70 | +100 |
| 기본 효과 추가 | 0% | 10% | 20% | 40% | 65% | 100% |

한계돌파는 같은 장비 여분 1개를 사용한다. 착용자 수만큼의 장비는 남겨야 하며, 아무도 착용하지 않아도 본품 1개는 남긴다. 돌파는 아이템 ID별로 저장되므로 같은 종류를 입은 인물들은 돌파 단계를 공유한다. 세트 효과에는 강화·돌파 배율을 적용하지 않는다. 진비뢰도도 현재 5성 기본 효과 보너스 +100%를 적용하되 새 고정 추가 옵션은 붙이지 않는다. 영웅 이상 장비만 1·3·5성에 장비별 고정 추가 능력치를 해금한다. 일반·고급·희귀에는 추가 옵션이 없다. 같은 종류 옵션의 기존 성별 기준 1:2:3에 영웅 1.2/1.4/1.7배, 전설 1.4/1.6/2배, 신화 1.6/1.8/2.3배를 추가로 곱한다. 치명타 확률은 이 배율을 적용하지 않으며 치명타 피해는 적용한다. 추가 옵션에 강화·기본 효과 보너스를 곱하지 않는다. 상세 배정은 [한계돌파 추가 능력치](BREAKTHROUGH_BONUSES.md)를 따른다.

강화는 인물별 여섯 부위(무기·상의·하의·신발·장신구 1·2)에 저장한다. 교체·해제·분해 시 유지되며 다른 인물에게 전달되지 않는다. 장신구 하나를 해제해도 다른 칸의 장비와 강화가 이동하지 않는다. 현재 장비의 상한보다 높은 강화는 보관하고, 등급 개방 후 전투에는 `min(저장 강화, 장비 상한)`을 적용한다. 미개방 장비는 강화 0으로 적용하되 기본·돌파 효과는 유지한다.

강화 증가량은 기본 효과에 +1~20 각 3%, +21~30 각 4%, +31~50 각 5%, +51~70 각 7%, +71~90 각 10%, +91~100 각 15%를 합산한다. 돌파 보너스도 같은 기본 효과에 합산한다. +100·5성은 기본 효과의 8.9배다. 기본 공격 +20% 장비라면 최종 공격 효과는 +178%다. 음수 효과도 기존처럼 같은 배율로 적용한다. 치명타율 상한 등 기존 전투 제한은 유지한다.

치명타 **확률**은 강화 증가분의 10%, 돌파 기본 보너스의 50%를 적용하고, 돌파로 해금하는 고정 치명타 확률 옵션도 이전 수치의 절반으로 줄인다. 일반~신화는 `기본 치명타 × [1 + 강화 보너스 × 0.1 + 돌파 보너스 × 0.5] + 해금된 고정 치명타 옵션`이다. 진비뢰도는 기존 5성 정의를 미돌파 기준으로 환산하는 분모 1.30을 유지하고 현재 보너스 1.00을 적용해 `0.30 × [1 + 강화 보너스 × 0.1 + 1.00 × 0.5] / 1.30`이다. 무강화 5성의 치명타 확률은 약 +34.62%p다. 5성 +100 기준 비뢰도 낙뢰는 +17.52%p, 진비뢰도는 약 +50.54%p다. 다른 능력치와 치명타 피해는 감쇠하지 않는다.

## 재료와 비용

강화는 구간별 재료와 두를 쓰며 성공률은 100%다. 다음 강화 단계 n에 필요한 재료는 `1 + (n-1)/10`의 정수 부분, 두는 `50 + 8n + 0.75n²`(반올림)다. +10까지 하급 영석 10개·1,230두, +50까지 44,900두, +100까지 총 재료 550개·299,175두가 든다(예전 `100 + 20n + 2n²`, 787,700두에서 낮췄다). 돌파에는 두·강화 재료를 사용하지 않는다.

| 강화 구간 | 재료 | 구간 전체 필요량 |
|---|---|---:|
| +1~20 | 하급 영석 (`gear_polish`, 기존 ID 유지) | 30 |
| +21~40 | 중급 영석 | 70 |
| +41~60 | 고급 영석 | 110 |
| +61~80 | 상급 현철 | 150 |
| +81~90 | 만년 현철 | 90 |
| +91~100 | 신물:천외비석 | 100 |

### 전투 드롭 (`GearDrops`)

재료 종류를 먼저 뽑고 개수를 독립적으로 뽑는다. 수량 0/2/4/6/8/10의 확률은 35/15/14/13/12/11%다(평균 3.7개). 수량 0은 보유 재료·획득 목록에 추가하지 않는다. 아래 비율은 수량과 무관한 재료 종류 추첨 확률이다.

| 난이도·스테이지 | 재료 종류 확률 |
|---|---|
| 일반 1~10 | 하급 영석 100% |
| 일반 11~20 | 하급 영석 55% / 중급 영석 45% |
| 일반 21~30 | 하급 영석 35% / 중급 영석 35% / 고급 영석 30% |
| 어려움 1~10 | 중급 영석 35% / 고급 영석 35% / 상급 현철 30% |
| 어려움 11~30 | 고급 영석 35% / 상급 현철 35% / 만년 현철 30% |
| 극악 이상 | 상급 현철 55% / 만년 현철 45% |

사용자 범위의 중복 경계는 1~10 / 11~20 / 21~30으로 해석한다. 보스(`EnemyData.IsBoss`)가 포함된 전투의 첫 승리는 해당 풀의 최고 등급 재료 7개를 확정 지급하고 위 일반 전투 추첨을 한 번 추가한다(보스가 여러 명이어도 확정 보상과 추가 추첨은 각각 한 번). 추가 추첨도 재료 종류·개수를 독립적으로 고른다. 같은 종류면 합산하고 다른 종류면 두 종류를 각각 지급·표시한다. 총 수량은 7/9/11/13/15/17개이며 각 확률은 35/15/14/13/12/11%, 평균 10.7개다. 일반 전투의 첫 승리와 보스 재전투는 모두 위 추첨을 따른다. 별 기록을 갱신하기 전에 첫 승리를 판정해 난이도별·전투별로 한 번만 지급한다. 구버전 일반 돌파 기록도 재전투로 인정한다. 탑·의뢰·승급 비무 등 이야기 스테이지 외 전투는 첫 승리·재전투 모두 강화 재료를 지급하지 않는다.

강화 재료의 직접 수급처는 이야기 스테이지 전투와 장비 분해로 제한한다. 예외로 새 게임 시작 꾸러미에서 하급 영석 5개를 한 번 지급한다. 일일 임무에서는 지급하지 않는다. 기존 보유 재료는 회수하지 않는다. 일반~전설 장비 분해는 기존 장비 제작용 합성 재료를 유지하고, 일반은 하급 영석·고급은 중급 영석·희귀는 고급 영석·영웅은 상급 현철·전설은 만년 현철을 추가로 준다. 강화 재료 수량은 매 장비마다 1~5개를 각각 20% 확률로 정한다. 일괄 분해도 장비마다 별도 추첨하며 예상·실제 획득 목록에 두 종류의 재료를 모두 표시한다. 신화·초월 장비의 분해 제한은 유지한다. 마지막 돌파 장비를 분해하면 확인창을 거쳐 돌파만 사라지며 부위 강화·등급 개방은 남는다.

강화 재료는 행낭의 재료 상세창에서 같은 등급 3개로 다음 등급 1개를 확정 합성한다. 두 비용은 없다. 2번 이상 할 수 있으면 개수 바(`CountBar`, −/+ 버튼과 끌기)로 몇 번 합성할지 고르고 한 번에 합성한다(`Gear.FuseMaterial(save, id, times)`, 처음에는 가능한 최대). 만년 현철 3개는 신물:천외비석 1개가 된다. 천외비석은 더 높은 등급으로 합성할 수 없다. 기존 장비 제작용 합성 재료의 비용·무작위 장비 합성 규칙은 유지한다.

천외비석은 이야기 전투(모든 난이도·재전투), 의뢰, 탑에서 직접 지급하지 않는다. 전투의 재료 종류·수량은 위 난이도별 드롭 표를 따른다. 천외비석은 만년 현철 3개 합성으로만 얻는다.

## 부위 등급 개방

등급 개방은 인물별·부위별로 저장한다. 일반은 무료이고 고급 추가 1,000두, 희귀 추가 3,000두, 영웅 추가 5,000두, 전설 추가 15,000두, 신화 추가 30,000두, 초월 추가 60,000두다(누적 고급 1,000·희귀 4,000·영웅 9,000·전설 24,000·신화 54,000·초월 114,000두). 이미 개방한 등급의 누적 금액을 빼고 청구한다. 따라서 처음부터 신화는 54,000두, 처음부터 초월은 114,000두이며 전설 개방 후 초월은 90,000두, 신화 개방 후 초월은 60,000두다. 이 가격이 생기기 전(영웅까지 무료)에 이미 강화한 부위는 지금 낀 장비 등급(영웅까지)이 개방된 것으로 한 번 옮겨 준다(`Gear.MigrateLowGradeUnlocks`, `SaveData.GearLowGradeUnlocksMigrated`). 상위 개방은 하위 등급도 포함한다. 개방 재료는 없으며 장비 중복을 요구하지 않는다.

미개방 장비도 장착·한계돌파할 수 있지만 부위 강화 보너스는 적용하지 않는다. 개방 후 저장 강화가 현재 장비 상한까지 즉시 적용된다. 미개방 등급 장비를 끼고 추가 강화할 수는 없다. 장비 교체·해제·분해 후에도 개방 기록은 유지되며 다른 인물·부위로 전달되지 않는다.

## 화면과 전승의식

행낭 장비 상세창에서는 한계돌파·분해를 한다. 목록은 장비 자체의 돌파 효과를 표시한다. 상태창의 인물·부위 선택창에서 장착·해제·부위 강화를 하고, 저장 강화·현재 적용·상한·재료·개방 비용을 함께 확인한다. 착용 장비가 미개방이면 강화 버튼 대신 등급 개방 버튼을 표시한다. 후보 효과는 그 부위에 장착했을 때 적용될 값으로 미리 표시한다. 장비 변경 창은 인물을 초상화 카드, 부위를 한 줄 가로 탭으로 구분한다. 현재 장착 카드에 저장·적용 강화와 강화 상한, 작은 강화/개방·해제 버튼을 모으고, 재료·두·개방 등급은 별도 자원 띠에 표시한다. 목록 뷰포트는 화면 높이의 약 45%를 사용한다. 장비 변경 창의 세트 효과는 상단에 한 번만 표시하며 후보 목록에는 능력치와 세트 이름만 표시한다. 후보 행을 누르면 설명·돌파 옵션·적용 강화·등급 개방 비용을 확인하는 상세창이 열리고 장착·해제할 수 있다. 상세창을 닫으면 목록의 스크롤 위치를 유지한다. 장비 능력치 표시에서 해금된 고정 돌파 옵션은 하늘색(`#8ECFFF`), 잠긴 옵션은 회색으로 구분하며 기본 능력치는 기존 색상을 유지한다. 행낭·상태창·장비 변경·상세·돌파 결과에서 같은 색상 규칙을 사용한다.

전승의식의 마지막 조건은 **5성 비뢰도 낙뢰 보유**다. 나머지 다섯 조건은 유지한다. 진비뢰도는 신규 지급과 기존 보유 모두 처음부터 5성, 강화 상한 +100이다. 정의에 저장된 능력치는 과거 +30% 돌파 보너스를 포함하므로 이를 1.30으로 나눈 뒤 현재 5성 보너스 +100%를 적용한다. 일반 능력치 배율은 `(1 + 강화 보너스 + 현재 5성 보너스) / 1.30`이며 치명타 확률은 강화 증가분 10%·돌파 보너스 50%를 적용한다. 현재 무강화 5성 효과는 체력 +46.15%·내공 +50%·공격 +184.62%·방어 +70%·속도 +30.77·치명타 +34.62%p·치명타 피해 +76.92%p다. 내공과 방어는 고정 추가 옵션이 아닌 기본 능력치로, 현재 5성 무강화에 +50%/+70%가 되도록 정의값 0.325/0.455를 사용한다. +100에서는 내공 +222.5%·방어 +311.5%로 증가한다. 새로운 고정 추가 옵션은 없다. 전승의식에서는 아이콘 → 보상 이름·5성 → 효과 순서로 표시한다.

## 구버전 저장 데이터

저장 버전 2를 유지하고 `GearProgressionMigrated`, `GearSlots`, `GearBreakthroughs`를 추가한다. 기존 아이템 강화 n(최대 10)은 `min(n,5)`성으로 옮기고, 소모했던 중복 중 5개를 넘는 분량은 장비 여분으로 돌려준다. 당시 착용자의 해당 부위에 기존 강화 보너스(단계당 10%) 이상이 되는 최소 강화 단계를 저장한다(예: 기존 +10은 새 +30). 미착용 장비의 강화는 비류연의 해당 부위에 저장한다. 같은 부위의 기존 강화가 여러 개라면 가장 높은 수치를 보존한다. 이전은 한 번만 실행하며 기존 진비뢰도는 5성으로 정규화한다.

추가 이전 플래그 `GearGradeUnlocksMigrated`와 슬롯의 `UnlockedGrade`를 저장한다. 기존에 강화된 착용 장비는 그 부위의 해당 등급을 무료 개방해 적용 중인 능력치를 보존한다. 이후 새 등급 개방에는 정상 비용이 든다. 기존 연마석은 ID·보유 수량을 유지하고 하급 영석으로 표시한다.

## 확인

강화 구간 경계, 여섯 상한, 다섯 돌파 보너스, +100 완주 비용, 부족한 재료·두의 원자성, 장비 교체 시 상한 적용·복원, 장신구 칸 독립, 동료별 강화, 기존 저장 이전·재이전 방지와 초월 지급을 Core 테스트로 확인한다. Unity 화면·터치·JSON 저장 왕복은 Unity에서 별도로 검증한다. 높은 강화까지 사용한 실제 전투 난이도는 기존 무강화 봇 결과만으로 보장하지 않는다.

이전 버전 검증 기록: 신규 성장 규칙 회귀 테스트 28개 통과(장비·동료·전승·슬롯 관련 71개 통과). 최신 원격 변경을 반영한 전체 Core 테스트는 391개 통과, 기존 초반 난이도 검사 2개가 동일하게 실패했다. Game/Core 및 Unity Editor용 UI·JSON 회귀 테스트 소스는 Unity API 참조 컴파일에 통과했다. Unity Editor·Android 실행과 JSON 런타임 왕복 테스트 실행은 이 환경에서 하지 못했다.

등급 개방·재료 구간 변경 검증: 전체 Core 440개 중 438개 통과. 기존 각성:강타 적용 후의 5스테이지 밸런스 검사 2개는 같은 결과로 실패했다(추천 레벨 0/40, 연속 진행 1/199). 직접·순차 개방 비용, 중복 결제 방지, 재료 경계별 소모, 기존 강화 저장 이전과 장신구 칸 이전을 확인했다. Core/Game 및 UI·JSON 테스트 소스는 Unity API 참조 컴파일에 통과했다. Unity Editor 실행 및 JSON 런타임 테스트는 수행하지 못했다.

분해·강화 재료 합성 변경 검증: 관련 91개 테스트 통과, 전체 Core 452개 중 450개 통과. 기존 5스테이지 난이도 검사 2개는 같은 결과로 실패했다. 등급별 분해 재료, 1~5개 균등 확률 구간, 일괄 분해 실제 합계, 다섯 단계 3:1 합성·재료 부족·최상위 합성 차단, 전투 보상 천외비석 제외를 확인했다. UI 소스 참조 컴파일 통과, Unity 화면 실행 검증은 미실시다.

전투 드롭 변경 검증: 신규 드롭 테스트 27개(구간 경계·재료/수량 독립 확률·첫 보스 확정·재전투·난이도별 첫 승리·기존 돌파 기록·탑 기록) 통과. 전체 Core 479개 중 477개 통과, 기존 5스테이지 난이도 검사 2개는 동일 결과로 실패했다. Core/Game 및 UI 테스트 소스 참조 컴파일 통과. Unity 화면 실행은 미실시다.

## 추천 장비와 착용자 표시

장비 화면의 캐릭터 위 「추천 장비」는 현재 사용 가능한 장비의 6부위 조합을 평가해 자동 장착한다. 캐릭터의 최종 능력치·장착/습득 무공·세트 보너스·부위 강화·등급 개방·돌파 상한을 고려한다. 다른 사람의 장비나 재료/은자는 소비하지 않는다. 목록에는 착용자 이름(여러 명이면 대표 이름과 인원수), 상세에는 전체 착용자를 표시한다. 평가 방식과 검증은 [EQUIPMENT_RECOMMENDATION.md](EQUIPMENT_RECOMMENDATION.md)를 따른다.
