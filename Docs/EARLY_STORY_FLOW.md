# 스테이지 1~18 상세 이야기와 재도전

## 진행 흐름

1~10권 재분석(`Story/analysis/vol01.md`~`vol10.md`)을 기준으로 사건과 대사를 재배치한다. 전투 수·상대·경험치·은자·첫 돌파 보상 및 저장 형식은 유지한다.

| 장 | 실제 진행 순서 |
|---|---|
| 1 아미산 숲 | 첫 비뢰도 수련 회상 → 열아홉 살의 일상·사부 막간 → 사냥과 비상금 → 수뢰비로 연결 → 폭포의 진조운 사고 → 두 달 뒤 변장과 주작단 첫 대면 → 합숙 중 백호 사건 → 치료와 수련 재개 |
| 2 중양표국 | 합숙 초기·연장 수련 회상 → 현재의 당철영 부상 → 인물·가문과 보상 논의 → 지원금 막간 회상 → 현재의 출발·표국 습격 → 강장한·쌍창·국주 대화와 전투 → 보상·윤색된 소문·귀향 준비 → 마지막 밤 남궁상과 진령의 약속 |
| 3 호골채 매복 | 노사부와 이별하는 아침 → 스승 없이 떠나는 표행 배경·막간 → 사천 경계 매복 → 호위 진형 유지 → 조천우와 패호 중광 → 무사상자 확인·정보 유출 의문·다음 길목 |

노사부 변장은 1장 주작단 대면 이후와 2장 전체에 유지한다. 3장 이별 장면에는 변장 입화를 쓰고 이후 제자들의 표행 장면에서는 사용하지 않는다. 실제 비뢰문 사부와는 구분한다. 현재 열아홉 살의 대장간 월급은 검장 승급 뒤 열 냥으로 맞춘다.

## 재도전

- 적용 범위는 일반 메인 스테이지 1~18이며, 어려움·극악도 같은 이야기 선택을 따른다.
- 최초 진입에는 상세 이야기를 기본으로 진행한다.
- 완료한 스테이지의 재입장, 저장된 이어하기, 패배 후 다시 도전에서는 두 방식을 고른다.
- **스토리 함께 보기**: 첫 전투부터 시작하며 배경·막간·전투 사이 대화·마지막 대화·후일담을 모두 제공한다. 중간 저장이 있으면 지우고 처음부터 새로 진행한다.
- **전투만 진행**: 이야기 창을 생략한다. 완료한 난이도에서는 기존 구간 선택을 사용하고, 이어할 지점이 있으면 그 지점과 기존 HP/내공/기세를 유지한다. 아직 완료하지 않은 스테이지의 패배 재도전은 처음부터다.
- 선택을 취소하면 이어하기 정보를 바꾸지 않는다. 보상 지급은 기존 전투·돌파 규칙을 따른다.
- 19장 이후의 재도전 방식은 이번 작업에서 변경하지 않는다.

`EarlyStory.Opening`과 `StoryEpisodes.BeforeFight`를 실제 진행에서 사용하고, 기록의 `ReplayScenes`도 같은 순서와 외형 정보를 사용한다. 1~18장의 기록은 해당 장 돌파 후에만 열리며, **전체 이야기** 버튼 하나로 배경부터 후일담까지 스테이지와 같은 순서로 읽는다. 배경·막간·본문·그 뒤의 중복 선택 버튼은 이 열여덟 장에서 제거한다. 기록 재생은 전투·보상을 실행하지 않는다.

## 검증

- 1~18장 실제 진행/기록의 대사 순서와 외형 경계, 완료 후 상세 재생과 단일 구간 생략을 NUnit으로 검사한다.
- 실제 RunStage의 재도전 준비 코드를 UI 대역에서 실행해 최초 진행·전체 재생·전투 구간 선택·전투 이어하기·전체 재시작·취소를 검사한다.
- 66장 전체의 전투 편성·권장 레벨·보상 예산 및 4~66장의 기록 대사를 변경 전 데이터와 대조한다.
- Unity 에디터가 없는 환경이므로 실제 화면 배치·터치·렌더링은 확인하지 못했다.

1~3장 작업 당시 검증: 관련 NUnit 31건 통과, 전체 Core 1,464건 통과·변경 전과 동일한 밸런스 12건 실패. UI 대역의 재도전 준비 6경로 통과, 66장 전투/권장 레벨/보상 예산 동일, 4~66장 기록 문자열 동일, Battle 151종·별칭 319개·적 300종·동료 7명의 조회 검사 통과. Game C# 9 구문 오류 0건이며 실제 Unity 타입 검사·렌더링은 미검증이다.

## 기록 열람 정리

1~18장 미돌파 이야기는 목록과 새 이야기 알림에 나타나지 않는다. 해당 장을 돌파하면 열리며 재생 직전에도 열람 가능 여부를 확인한다. 돌파 전에는 빈 목록 안내를 표시한다. 19장 이후의 기존 미리보기와 네 부분 구성은 이번 변경 범위에 포함하지 않는다. 이야기 내용·진행 순서·외형 메타데이터·전투·보상은 바꾸지 않는다.

1~3장 기록 열람 작업 당시 검증: 관련 NUnit 38건 통과, 전체 Core 1,468건 통과·기존 밸런스 실패 12건 동일. 실제 StoryLogPanel 소스를 UI 대역과 함께 컴파일·실행해 미돌파 빈 목록, 돌파 장별 단일 전체 이야기 버튼, 클릭 직전 잠금, 재생 순서, 3장 외형 경계 및 4장 기존 버튼 유지를 확인했다. Game 61개 파일 C# 9 구문 오류 0건이다. Unity 실제 화면은 미검증이다.

## 스테이지 4~6 확장

| 장 | 배치 |
|---|---|
| 4 용골채 매복 | 호골채 다음 길목의 배경·첫 공방 → 전투 사이 천 명의 계산 막간 → 패룡 우악 → 일곱 달 만의 귀환·표행 후일담 |
| 5 주주 윤하루 | 주작단 출발 이튿날의 사부 대면 회상 → 계절이 흘러 겨울·새해의 스무 살 가출 → 맨얼굴 표사와 장우강 → 윤하루 상세 배경·노사부 서찰 막간 → 염도 내기·동행 후일담 |
| 6 남창 호아장 | 표행 뒤 남창·마감된 입관시험 → 장터 짐꾼 막간 → 추천패 목적·호아장 정문 → 문하 저항 → 장주의 대치 → 빙검 등장·승룡패·입관 준비 |

5장 배경 중 객잔 대화는 염도전 직전에, 6장 도입 중 운수의 패배와 장주 대화는 문하 제자전 뒤에 배치한다. 기존 배경·막간·그 뒤 문자열 API는 보존하고 공유 장면 배열에서 순서를 나눈다. 4~6장도 전체 이야기/전투 전용 재도전, 이어하기, 패배 재도전 및 돌파 후 단일 기록 버튼을 사용한다. 전투 수·상대·레벨·보상·저장 형식은 유지한다.

4~6장 확장 검증: 관련 NUnit 46건 통과, 전체 Core 1,476건 통과·기존과 동일한 밸런스 12건 실패. 4장 37개·5장 72개·6장 57개 대사/지문에 기존 배경·막간·후일담이 모두 포함된다. 변경 전 스냅샷과 대조해 66장 전투/레벨/보상 예산 및 1~3장·7~66장 기록 문자열이 동일함을 확인했다. 실제 RunStage 재도전 준비 코드와 StoryLogPanel을 UI 대역에서 실행해 4~6장 전체 재생·전투 전용·이어하기·단일 기록 버튼을 검사했다. Game C# 9 구문 오류 0건이다. 실제 Unity 렌더링은 미검증이다.

## 스테이지 7~12 확장

| 장 | 배치 |
|---|---|
| 7 특별전형과 검혼관 | 승룡패·임명 서류와 월급 막간 → 네 응시생 → 입관·효룡·장홍 → 검혼관 기관 → 호천강 → 사감 문책·룸메이트·저녁 식사 약속 |
| 8 천무식당 | 정식 메뉴·윤준호 배경·식당 막간 → 선배들의 모욕 → 머릿속의 공방 → 모용휘 중재 → 검향 진단·다음 날 수련 준비 |
| 9 천무학관 운향정 | 식당 소동 뒤 밤·편람 막간 → 다음 날 수강신청·우뢰매 → 첫 역사 수업 → 동호회·애소저회 → 구정회·암기 수업 → 운향정 소녀·위지천 → 보고·제자들 귀환 |
| 10 백향관 침투 | 운향정 사건 일주일 뒤 이름 탐색·정보값 흥정 → 나예린 신원 → 음율관·나예린 측 장면·추일태 내기 → 한 달 뒤 잠입 → 같은 밤의 탈출·별도 침입·나예린의 의심 |
| 11 승급시험 | 침투 이튿날 새벽·비무첩 막간 → 애소저회의 우승 약속 → 내기 정산 → 대사형·학관 일상 → 곤륜쌍검·승급 → 그날 밤 |
| 12 삼성무제 본선 | 개막일 묵금 준비·개막식 → 우뢰매의 초대 수락 → 대진 준비·관중석 → 첫 승리 → 홍란 막간과 반응 → 연승·전옥기 → 후일담 |

9장의 수강신청 준비와 10장의 이름 탐색은 발견 장면보다 먼저 재생한다. 10장 후일담의 정산 부분은 11장의 약속 뒤로, 11장 끝의 개막 준비는 12장 개막식 앞으로 옮긴다. 12장의 대진 대화는 초대 수락을 확인한 개막 뒤의 대기 공간으로 명시하고, 격타금 반응 막간은 첫 승리 뒤에 둔다. 이 이동은 내용을 삭제하지 않고 두 장의 경계를 바로잡는 것이다. `EarlyStory.Ending`을 전투와 기록 모두에서 사용한다.

7~12장에도 전체 이야기/전투 전용·이어하기·패배 재도전 선택, 돌파 후 단일 기록 버튼을 적용한다. 전투 수·상대·레벨·보상·저장 형식은 유지한다. 1~6장과 13장 이후 이야기는 유지한다.

7~12장 확장 검증: 관련 NUnit 62건 통과, 전체 Core 1,492건 통과·기존 밸런스 실패 12건 동일. 변경 전 기록의 대사는 정산/개막 장면 이동을 포함해 7~12장 전체에 보존되었다. 재생 분량은 7장 58개·8장 45개·9장 103개·10장 76개·11장 105개·12장 73개 대사/지문이다. 66장 전투/레벨/보상 예산과 1~6장·13~66장 기록 문자열은 변경 전과 동일하다. 실제 RunStage 준비 코드와 StoryLogPanel을 UI 대역에서 실행해 12장까지 전체 재생·전투 전용·이어하기·단일 기록 버튼을 검사했다. Game C# 9 구문 오류 0건이며 Unity 실제 화면은 미검증이다.

구간 선택창의 고정 5개 제한도 제거했다. 전투 수에 맞춰 두 열의 스크롤 목록을 만들고, 이전 목록을 정리한 뒤 첫 위치로 연다. 따라서 7장 8번째 전투와 12장 6번째 전투도 직접 선택할 수 있다. 실제 PickFight 메서드를 UI 대역에서 실행해 66장 모든 구간 수·마지막 버튼 선택·이전 목록 비활성화·스크롤 영역 안 배치를 검사했다. 다른 스테이지의 전투/이야기 데이터는 바꾸지 않는다.

## 스테이지 13~18 확장

| 장 | 배치 |
|---|---|
| 13 삼성대전 결승 | 안목품평회·내기 막간 → 당철영의 경고 → 준결승 대기실 배경 → 각 부문 승부·위지천 → 우승·사과·정산 후일담 |
| 14 무당산 고립 | 삼 년 전 사부 수련 회상 → 현재 연말 단체전 → 패배를 인정한 맹연호 → 새해 합숙지 막간·무당산 결정 → 장강·육로·합숙지·동굴·형제 → 합숙지 후일담 → 관주실의 신병 요구 |
| 15 철각비마대 | 현재 진혼제 → 청흔의 회상으로 길목 대치·기마대전 → 철수·귀환길 → 현재의 청흔 |
| 16 저잣거리 습격 | 사신·조사관 출발 → 조사관을 맞은 뒤의 호위 배경 → 쇼핑 막간 → 호위를 이어 가던 날 저잣거리 → 암습·쌍귀·백탄저 → 호위 추가 요청 |
| 17 마하령의 분노 | 대표 후보·흑검조 수업 → 무당산 맹세 회상 → 현재의 경고·배경·정기전 막간 → 길모퉁이 대치 → 끝나지 않은 갈등 |
| 18 태극의 인재 | 용천명 소개·대치 → 백룡검을 뽑음 → 칼집 설명 막간 → 사흘 전 순풍루 회상·현재의 한 합 → 중간 평가·빙검의 별도 시험 → 승부·첫 부탁·두 노사 |

14장 배경은 연말 단체전 승리 이후에 배치한다. 기존 전투 사이 장면의 패배 인정과 새해 합숙지 장면을 나누어, 합숙 공지 막간이 연말 승부보다 먼저 나오지 않도록 했다. 첫 습격을 언급하는 배경은 실제 첫 습격 뒤에 둔다.

15장의 철각비마대전은 진혼제 이후 새로 일어나는 전투가 아니라 청흔의 회상이다. 귀환길 설명까지 회상 안에 두고 현재의 대화로 돌아온다. 16장은 사신·출발 뒤 조사관을 맞은 시점으로 호위 배경을 표시하고, 17장의 과거 맹세와 현재 경고를 구분한다. 18장 칼집 설명은 백룡검을 뽑은 뒤로 둔다.

갈효봉이 끝까지 조종당했다고 말하던 후일담 한 문장은 본문의 심뢰·기억 회복에 맞춰 마지막에 정신을 되찾았다는 내용으로 바로잡았다. 사망·생환·정치적 결과는 바꾸지 않는다.

13~18장도 상세 이야기/전투 전용·이어하기·패배 재도전 선택, 돌파 후 전체 이야기 버튼을 사용한다. 전투 편성·레벨·보상·저장 형식과 1~12장·19장 이후 이야기는 유지한다.

13~18장 확장 검증: 관련 NUnit 143건 통과(중반부 이야기 포함), 전체 Core 1,507건 통과·기존 밸런스 실패 12건 동일. 재생 분량은 13장 114개·14장 130개·15장 69개·16장 59개·17장 79개·18장 98개 대사/지문이다. 확장 직전 소스를 재구성해 비교한 결과, 문서에 적은 갈효봉 회복 문장 수정 외에 기존 13~18장 대사·지문이 모두 보존되었고, 전체 66장 전투/레벨/보상 예산 및 1~12장·19~66장 기록 문자열이 동일하다. 실제 RunStage 준비 코드와 StoryLogPanel을 UI 대역에서 실행해 18장까지 전체 재생·전투 전용·이어하기·돌파 후 단일 기록 버튼을 확인했다.
