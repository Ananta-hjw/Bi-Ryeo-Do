# 오디오 가이드

소리는 그림처럼 **파일 이름으로 자동 적용**된다. 파일이 없으면 조용히 넘어가므로 하나씩 채워 넣어도 된다.

- 효과음: `Assets/_Project/Resources/Audio/Sfx/<이름>.ogg` (wav, mp3도 가능)
- 배경음: `Assets/_Project/Resources/Audio/Bgm/<이름>.ogg` (반복 재생)
- 효과음은 0.5초 안팎의 짧은 소리가 좋다. 같은 소리가 0.04초 안에 다시 나오면 건너뛴다(연타 소음 방지).
- Unity에서 파일을 넣을 때 `.meta`도 함께 커밋한다.

## 효과음 이름

| 이름 | 언제 |
|---|---|
| `ui_click` | 모든 버튼을 누를 때 |
| `hit` | 아군이 적을 때릴 때 (연타마다) |
| `hit_crit` | 아군의 치명타 |
| `hit_taken` | 아군이 맞을 때 |
| `block` | 방어로 피해를 줄였을 때 |
| `dodge` | 회피했을 때, 회피 태세를 쓸 때 |
| `guard` | 방어 / 파티 방어 |
| `heal` | 운기조식, 치유, 아이템 사용 |
| `charge` | 적이 강한 기술을 모을 때 |
| `skill` | 일반 무공 컷인 |
| `ultimate` | 비기와 합공 컷인 |
| `enemy_down` | 적이 쓰러질 때 |
| `win` | 전투 한 판에서 이겼을 때 |
| `levelup` | 레벨 업, 무공 숙련 단계 상승 |
| `clear` | 스테이지 돌파, 의뢰 완수 등 결과 화면 |
| `lose` | 패배 |
| `gacha_pull` | 뽑기에서 일반~고급~희귀가 나올 때 (한 장마다) |
| `gacha_rare` | 뽑기에서 영웅이 나올 때 |
| `gacha_mythic` | 뽑기에서 전설·신화가 나올 때 |

## 배경음 이름

| 이름 | 언제 |
|---|---|
| `lobby` | 강호/무공/행낭 화면, 전투가 끝나고 돌아왔을 때 |
| `battle` | 일반 전투 |
| `boss` | 보스가 있는 전투 |

## 진동

설정 화면에서 켜고 끈다. 치명타, 피격, 비기, 패배 때 짧게 울린다(안드로이드 기기에서만).

## 소리 구하기 팁

- 무료 효과음 사이트의 CC0 / 상업 이용 가능 소리를 쓰면 된다 (개인용이라 저작권 부담은 적지만, 출처를 적어 두면 좋다).
- 배경음은 1~2분 루프가 이어 붙기 쉬운 곡이 좋다.
