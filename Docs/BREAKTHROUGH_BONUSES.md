# 한계돌파 추가 능력치

미돌파~5성 기본 효과 보너스는 **0 / 10 / 20 / 40 / 65 / 100%**다. 각 수치는 해당 성의 총 보너스이며 성별 수치를 모두 더하지 않는다. 강화 상한과 강화 증가량·소모품 비용·중복 장비 소비는 그대로다.

진비뢰도를 제외한 영웅 이상 장비만 1·3·5성에 원래 없던 능력치를 하나씩 누적 해금한다. 추가 옵션은 장비 등급과 역할에 따라 정하며 강화와 기본 효과 보너스를 곱하지 않는 고정 수치다. 치명타·치명타 피해의 %p는 확률·배율에 직접 더하는 값이다. 기본 장비의 음수 효과는 기존처럼 유지된다. 아래 표는 **그 성에 새로 열리는 옵션**이며 5성에는 세 열이 모두 적용된다.

## 추가 옵션 수치 기준

아래 비율은 **변경 직전 각 성의 옵션 수치에 곱하는 배율**이다. 기존 1:2:3 기준을 대체하지 않는다. 치명타 확률 옵션은 배율을 적용하지 않고 유지한다. 치명타 피해는 배율 적용 대상이다.

| 등급 | 1성 | 3성 | 5성 |
|---|---|---|---|
| 영웅 | 120% | 140% | 170% |
| 전설 | 140% | 160% | 200% |
| 신화 | 160% | 180% | 230% |

같은 종류 옵션의 조정 후 1성 / 3성 / 5성 수치다. 장비마다 배정된 종류는 다르다.

| 옵션 | 영웅 | 전설 | 신화 |
|---|---|---|---|
| 체력·내공·공격·방어 | 6 / 14 / 25.5% | 9.8 / 22.4 / 42% | 16 / 36 / 69% |
| 치명타 | 1.25 / 2.5 / 3.75%p | 1.5 / 3 / 4.5%p | 2 / 4 / 6%p |
| 치명타 피해 | 12 / 28 / 51%p | 19.6 / 44.8 / 84%p | 32 / 72 / 138%p |
| 속도 | 2 / 6 / 10 | 4 / 10 / 18 | 6 / 14 / 28 |
| 시작 기세 | 5 / 11 / 20 | 8 / 19 / 36 | 13 / 29 / 55 |

속도·시작 기세는 배율까지 곱한 뒤 정수 반올림한다. 시작 기세는 현재 뇌금 묵뢰 5성에만 배정되어 +55가 적용된다. 옵션의 종류가 다르므로 서로 다른 능력치의 숫자 자체를 직접 비교하지 않는다.

## 계산과 적용

일반~신화는 `기본 효과 × (1 + 강화 보너스 + 돌파 보너스) + 해금된 고정 추가 옵션`이다. 단 치명타 확률은 강화 증가분만 10%를 적용한다. 돌파 기본 보너스는 50%를 적용하며 새 치명타 확률 옵션은 기존의 절반이다. 다른 능력치와 치명타 피해는 감쇠하지 않는다. 세트 효과에는 이 배율을 적용하지 않는다. 인물·부위 강화는 기존처럼 유지하고, 추가 옵션은 장비 ID의 돌파 단계에 귀속한다. 장비를 교체하면 그 장비의 옵션을 사용하며, 같은 장비를 입은 동료도 공유한 돌파 단계에 맞게 적용한다. 등급 미개방은 부위 강화 보너스만 제한하며 돌파 보너스·추가 옵션은 적용한다.

진비뢰도도 현재 5성 기본 보너스 +100%를 적용하며 새로운 고정 추가 옵션은 붙이지 않는다. 과거 +30% 보너스를 포함한 정의를 환산하는 분모 1.30은 유지한다. 일반 능력치 배율은 `(1 + 강화 보너스 + 현재 5성 보너스) / 1.30`이다. 치명타 확률에는 강화 증가분 10%·현재 돌파 보너스 50%를 적용한다. 신규 지급과 기존 보유 모두 같은 규칙을 따른다.

조정 후 진비뢰도 5성·강화 미적용 실제 표시: **체력 +46.2%  공격 +184.6%  속도 +31  치명타 +34.6%  치명타 피해 +76.9%**.

일반·고급·희귀에는 추가 옵션이 없다. 영웅 이상은 등급이 높을수록 동일 종류 옵션의 수치가 커지고, 기존 성별 기준 1:2:3에 위 등급별 조정 배율을 곱한다. 치명타 확률은 조정 배율을 적용하지 않는다. 속도·시작 기세는 정수 반올림한다. 기본 효과에 이미 있는 능력치와 페널티는 새 옵션 후보에서 제외한다.
