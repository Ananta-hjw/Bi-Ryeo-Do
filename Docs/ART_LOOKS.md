# 캐릭터 외형 정리

`Docs/ART_NAMES.md`에는 파일 이름과 진영만 있고 외모 설명이 없어서, 이 파일에 외형을 따로 정리한다. 그림을 새로 만들거나 고를 때 참고하는 용도다.

## 읽는 법

- **그림** 열: `Assets/_Project/Resources/Art/Standing/`에 그 파일이 있으면 ✅, 없으면 ❌(게임에서는 이름 첫 글자 색 블록으로 나온다). 다른 적의 그림을 같이 쓰는 인물은 ✅ 공유(원본 파일 이름)로 적었다.

- **대사** 열: 게임 안 대화 장면(`화자|대사` 줄)에서 이 이름으로 말하는 인물이면 💬 있음, 한 번도 말하지 않으면 -. 화자 이름이 일부만 같으면 같은 인물로 보았다(예: 화자 「구창」 = 일도파쇄 구창). 같은 인물의 변형 행(백일연무, 폭주, 은가면 셋 등)은 모두 표시했다. 짐승·기관·산적 무리는 대사가 없다.
- **원작 확인**: `Story/CHARACTERS.md`와 `Story/analysis/volXX.md`에 실제로 적혀 있는 외형·복장·소지품이다. 이것만 사실로 취급한다.
- **느낌(추정)**: 직함·무공·성격·역할에서 받은 인상으로 게임 그림용으로 덧붙인 제안이다. 원작 설정이 아니므로 마음에 들지 않으면 바꿔도 된다.
- 원작에는 얼굴 생김새 묘사가 거의 없다. 얼굴은 정하지 않았고, 그림을 뽑을 때마다 달라진다(`Docs/ART_GUIDE.md`와 같은 방침).
- 파일 이름은 `Docs/ART_NAMES.md`와 같다. 17권 이후에 나올 인물은 아직 분석 전이라 넣지 않았다.

- 원작 확인 외형이 있는 인물은 염도(붉은 머리·눈썹·수염), 빙검(은청색 머리), 구창(흑삼·짙은 눈썹·강인한 턱), 위지천(청색 비단 무복·흰 술 보검), 독고령(왼쪽 안대), 위천무(반면 은가면·황금빛 눈), 사부(은빛 수염과 흰 갈기 같은 백발) 정도이다. 이들은 그림을 새로 만들 때 이 특징을 먼저 맞추면 된다.
- 은가면 세 명(공포·절망·비탄)의 정체는 천무삼성(검성·도성·검후)이다. 그림에서 닮게 그릴지는 정하면 된다. 위 표의 닮은 정도는 느낌일 뿐이다.
- 같은 사람인데 장면이 다른 파일(위지천 3종, 종리추·도추운 낮밤, 나예린 2종, 천살·지살과 쌍살 합격술)은 옷과 머리 모양을 통일하면 좋다.

## 전체 탭 공통 테마

- 협객·장비·무공/심법·뽑기·행낭·기록은 같은 먹녹색 패널, 밝은 금색 제목·모서리 장식, 낮은 채도의 주홍색 선택 버튼을 사용한다. 글자 패널의 불투명도는 94% 이상으로 유지해 배경과 구분한다.
- `UiFactory.MenuBackdrop`은 기존 화면별 산수화와 24% 먹색 막을 조합한다. 협객/행낭은 객잔, 장비는 대장간, 무공은 수련장, 뽑기는 누각, 기록은 서고 배경이다. 전투·대화는 7~66장 전용 배경 60장과 기존 초반 테마를 사용하고, 여정 지도는 6지역씩 총 11장의 그림을 사용한다(`Docs/SCENERY_ART.md`).
- 의뢰·도전·파티·설정 및 일일 임무·별 보상·객잔·도감·업적·추억·세력 등은 창을 다시 그릴 때 같은 배경·금색 테두리를 재생성한다. 장비·무공·심법 상세, 도움말·분해·합성·확인창도 같은 패널색을 사용한다.
- 대화는 입화를 두 개의 마스크 영역에 배치하고 상반신을 확대한다. 대사·이름판은 그 위에 놓이며, 그림은 장 이름·건너뛰기와 상대 영역을 가리지 않는다. 대화 진행·페이지 분리·건너뛰기 동작은 유지한다.
