# 캐릭터 투명 배경 검사 (2026-10-29)

대상은 `Assets/_Project/Resources/Art/Standing` 146장과 `Battle` 82장, 합계 228장의 PNG다. 캐릭터 그림을 사용하는 두 폴더 전체를 검사했으며, 장면 배경과 아이템 그림은 대상에 포함하지 않았다.

모든 파일의 PNG 디코딩·RGBA 채널을 확인하고, 네 모서리 픽셀·24×24 패치·전체 테두리의 알파값을 비교했다. 검출된 후보는 원본을 열어 무기·옷자락 등 실제 캐릭터와 배경을 구분했다. 알파값이 0이 아닌 픽셀을 일괄 삭제하거나 검은색을 색상 기준으로 지우는 방식은 사용하지 않았다.

위 3장은 이미지 편집 도구로 배경·비네트·주변 안개를 제거했다. 1024×1536 RGBA 형식과 파일명, Unity `.meta` 및 GUID는 그대로 유지했다. 검은 머리카락과 의상은 캐릭터로 보존했다.

수정 후 세 파일 모두 테두리에 알파값 10/255 초과 픽셀이 없다. 이 기준은 눈에 보이는 배경 잔여물 검출을 위한 것으로, 투명도 1/255 같은 미세한 안티앨리어싱 노이즈를 캐릭터 손상 없이 구분하기 위해 사용했다.

`Standing/jeok_hyeol.png`, `Standing/yonggol_bandit.png`, `Battle/ho_cheongang.png`는 모서리 근처의 창·칼 끝, `Battle/default_assassin.png`는 가장자리에 닿은 캐릭터 실루엣으로 확인했다. 배경으로 판단해 삭제하지 않았다. 나머지 파일의 모서리에는 위 세 수정 파일과 같은 넓은 배경 오염이 검출되지 않았다.
