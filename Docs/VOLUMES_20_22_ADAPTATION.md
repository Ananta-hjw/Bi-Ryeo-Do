## 회상과 장면 전용 기술

- 어린 연비는 비류연의 현재 레벨·장비·장착 무공·심법을 가져오지 않는다.
  능력치는 고정된 곡선30에 해당 난이도의 `StageStars.LevelAdd`만 더해 만든다. 같은 난이도에서는 성인 장비를 강화하거나 레벨을 올려도 같고, 경지 보너스는 한 번만 적용한다.
- 첫 공방은 적4행동 버티기이며 팔화난무·회피를 사용한다. 두 번째는14아군 행동 안에 관통하는 공방으로 충각 쌍섬일격뢰를 사용한다.
  `Roster.PrepareStoryEncounter`가 같은 인물의 무공만 바꾸므로 체력·내공·기세를 새 몸으로 초기화하지 않는다.
- 이후 독니·중독·노사부의 처치와 구조는 고정 이야기 결과다. 플레이어 실수로 표시하거나 백교를 어린 연비가 끝내 죽인 결말로 바꾸지 않는다.
  백응 새끼는 린이 맡으며 펫이나 장비 보상으로 지급하지 않는다.
- 현재 연비·마하령 등 임시 인물은 기존 고정 시점 방식대로 비류연의 준비 능력치와 장면용 기술을 사용한다. 정규 장홍·준호·나예린은 각자의 기존 육성 상태를 사용한다.
