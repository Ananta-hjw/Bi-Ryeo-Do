# Story

게임(비려도)의 세계관과 줄거리를 담는 폴더. 스테이지 문구, 적/보스, 이벤트, 대사를 만들 때 **먼저 여기를 참고한다.**

## 구조
| 경로 | 내용 |
|---|---|
| `raw/` | 사용자가 제공한 원문 1~28권 (수정하지 않는다) |
| `analysis/volXX.md` | 권별 분석 (`analysis/_TEMPLATE.md` 형식) |
| `INDEX.md` | 권별 분석 진행표 |
| `MAIN_STORY.md` | 분석이 끝난 권을 이어 붙인 **주요 스토리** 연대기 |
| `SUBSTORIES.md` | **서브 스토리** 목록 (어느 권에서 시작/종결, 메인과의 연결) |
| `CHARACTERS.md` | 인물 · 세력 · 용어 사전 |
| `GAME_MAPPING.md` | 스토리 → 게임 요소 (스테이지, 적, 보스, 무공, 이벤트) 연결표 |

## 분석 절차 (한 권씩)
1. `raw/`의 해당 권을 끝까지 읽는다 (길면 나눠서 읽되 요약하지 않고 건너뛰지 않는다).
2. `analysis/_TEMPLATE.md`를 복사해 `analysis/volXX.md`를 채운다. 원문에 없는 내용은 추측해서 쓰지 않고 "불명"으로 둔다.
3. 사건을 **주요 스토리**(주인공의 목적/전개를 움직이는 줄기)와 **서브 스토리**(곁가지, 인물 일화, 세계관 설명)로 나눈다.
4. `MAIN_STORY.md`, `SUBSTORIES.md`, `CHARACTERS.md`, `GAME_MAPPING.md`, `INDEX.md`를 갱신한다.
5. 이전 권에서 던진 복선이 해소되었는지 확인해 이전 분석의 "미해결 복선"을 갱신한다.
