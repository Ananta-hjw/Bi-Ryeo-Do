상태 이상(게임 규칙): 적 기술의 상태 이상은 원작에서 온 기술 이름(독침·절독난무·독편 난무·맹독 난자 = 중독, 화령염천도세·화룡의 숨결·명염참 등 = 화상, 빙령수혼·백빙신침·백빙신정 = 한기, 혈검·혈풍무·굉천혈류패왕십자인 등 = 출혈)을 게임이 해석한 것이다. 나예린 한상옥령신검의 한기는 무공 설명("얼음처럼 차가운 검기")에 근거한다. 비류연 무공의 상태 이상(분뢰수 내상, 비뢰도·뢰광류하곡 출혈, 천근뢰 화상)과 윤준호 자하청심결, 해독 영약은 원작 근거가 없는 게임 연출이다.

원거리 연출: 비도 던지기·비뢰도·굉뢰는 기존 기술 설명, 기관 화살·비침은 2권 기관 던전, 혈마전·혈야구성은 11권 혈궁의 활, 창 투척은 14권 칠련창 묘사에 맞춰 제자리 공격으로 표시한다. 적 암기·독액·불길도 기존 전투 기술에 원거리 연출만 지정하며 새 기술·대사·전투 수치를 추가하지 않는다. 긴 사거리나 저격 대상 선택만으로 원거리로 분류하지 않는다.

## 본편 전투 확장 (콘텐츠 리비전 2)

별도 외전 목록과 고정 능력치 전투를 삭제했다. 추가 장면은 모두 기존 본편 번호 안의 필수 개별 전투다.
`BattleScreen.RunStage`의 일반 전투·보상·별·정비·이어하기 흐름을 그대로 사용한다.
현재 저장 데이터의 레벨·장비·심법·장착 무공·편성 파티를 사용하며, 실제 소모품도 사용할 수 있다.
원작에서 동료가 싸운 장면은 이야기의 당사자를 유지하되 현재 편성 파티로 재현한다고 안내한다.
모용휘나 나예린을 이 시점에 새 동료로 지급하거나 능력치를 빌려 주지 않는다.

| 출처 | 본편 | 전투 구성 |
|---|---|---|
| 1권 | 2 중양표국 · 5전 | 표사 → 표사 2명 → 강장한 → 등여운·등여호 → 장우양 |
| 2권 | 7 특별전형과 검혼관 · 8전 | 특별전형 응시생 4명 → 기관 3전 → 호천강 |
| 4권 | 11 승급시험 · 4전 | 곤륜쌍검 → 오문형 → 장대평 → 단대풍. 이후 강현추는 무전투 기권 |
| 5권 | 12 삼성무제 본선 · 6전 | 단평 → 조연일 → 진패 → 일연 → 언가영 → 전옥기 |
| 5권 | 13 삼성대전 결승 · 4전 | 당문천 → 관설지(버티기) → 청흔(버티기) → 위지천 |

7의 합격·입관식은 응시생 4전을 마친 뒤 기관 전투 직전에 재생한다.
13의 검후전 결과는 청흔전 직전, 검성전 결과는 위지천전 직전에 재생한다.
무승부 공방은 적 12행동을 견디는 게임 목표로 압축한다. 기술·능력치·목표 숫자는 게임용 각색이다.
전용 그림이 없는 인물은 기존 `Art/Battle` 그림 또는 기본 인물 그림을 사용한다.

### 추가 성장 보상

모든 추가 전투는 경험치·두·별·재료·일반 전리품·숙련·동료 경험치를 일반 규칙대로 지급한다.
`StageData.RewardWeightBudget`에 확장 전 보상 분모를 보존해 새 전투가 기존 보상을 나눠 가지지 않도록 한다.
기존 일반 적은 가중치 1, 보스는 3의 보상 단가를 그대로 쓰며 다음 비율만큼 총 경험치·두가 늘어난다.

| 본편 | 전체 가중치 / 기준 분모 | 기본 총보상 배율 |
|---|---|---|
| 2 | 9 / 7 | 약 1.286배 |
| 7 | 12 / 8 | 1.5배 |
| 11 | 7 / 3 | 약 2.333배 |
| 12 | 8 / 6 | 약 1.333배 |
| 13 | 6 / 4 | 1.5배 |

정수 반올림 차이가 있고 난이도·평판·수입 배율·재도전 감액은 기존 규칙을 따른다.
어려움·극악에도 확대된 총보상을 적용한다. 의뢰·탑에는 본편의 기준 분모를 적용하지 않는다.
재료 확률과 보스 첫 승리 보장은 유지하므로 늘어난 본편 전투만큼 재료 획득 기회도 늘어난다.
단계별 일반 적·최종 보스 구분을 유지하며 중양표국의 보스 보장은 최종 장우양전 한 번이다.

### 저장 데이터 호환

`StoryContentMigration`은 리비전 0→1→2를 순서대로 처리한다. 기존 스테이지 번호·해금 조건·보상 수령은 유지한다.
기존 7의 별 기록은 전투 인덱스 +4, 기존 11 단대풍 기록은 3, 기존 13 위지천 기록은 3으로 옮긴다.
리비전 0의 2·11·12 기록 변환과 삭제된 전투의 `RetiredStoryStars` 보존도 계속 지원한다.
순서가 바뀐 스테이지의 중간 이어하기만 초기화하고 이미 얻은 성장과 별은 보존한다.
`CompletedStoryBattles`는 옛 저장 호환 필드로만 남으며, 완료·보상 판정에 쓰지 않는다.

### 검증

스토리·구성 관련 33건 통과. 변경된 본편 2·7·11·12·13은 준비된 현재 육성 빌드로 각각 40개 난수 시드를 통과했다.
전체 Core 592건 중 577건 통과, 기존 실패 15건은 확대 전과 같은 테스트들이다.
이는 새 보상으로 첫 회차 전체를 진행할 때의 모든 난이도나 실제 터치 조작을 보장하는 검사가 아니다.
Game/UI 테스트 소스까지 Unity API 참조로 컴파일했으며, Unity Editor 실행·화면·터치 검증은 수행하지 못했다.

## 환경 배경 연결 (2026-10-23)

기존 30개 스테이지의 장소를 7개 재사용 배경 테마로 연결했다. 아미산·무당산 수련은 숲, 산채와 이동전은 산길, 표국·객잔·호아장·식당은 장원 뜰, 승급시험·삼성무제는 학관 비무장, 운향정·백향관은 야간 누각, 검혼관·환마동·중토관은 기관·동굴, 낙뢰곡 이후의 매복·진법 전장은 협곡 테마를 사용한다. 원작 장소를 사건마다 그대로 재현한 그림이 아니라 분위기를 공유하는 게임 배경이다. 사건·대사·전투·보상은 변경하지 않았다. 정확한 스테이지별 연결은 `Docs/SCENERY_ART.md`와 `Game/Systems/SceneryArt.cs`에 기록했다.
